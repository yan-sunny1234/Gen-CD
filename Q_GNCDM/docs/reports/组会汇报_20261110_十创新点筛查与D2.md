## 一、研究背景与本阶段工作概览

**基线模型**：G-NCDM 用固定专家 Q 矩阵连接题目与知识点，Q 参与两处计算——学生显式掌握生成 θ_exp = σ(R·Q/√K)，以及预测掩码 θ⊙q、ψ⊙q。

**我们的主线**：真实数据中 Q 来自专家标注/技能标签/元数据，质量参差。把 Q 从"固定常量"改为"弱监督可学习的软矩阵"（Weak-Q），并在同一实验协议下检验对比学习（CL）能否进一步改善诊断。

**此前已确立的两块地基**（本阶段的地板）：

1. **Weak-Q 的预测收益在五套真实数据上一致为正**（3 训练种子配对、按验证 AUC 选模）：

| 数据集 | A0→A1 ΔAUC | ΔACC |
| --- | ---: | ---: |
| Math1 | +0.0056 | +0.0041 |
| Math2 | +0.0071 | +0.0030 |
| Eedi Task3/4 | +0.0084 | +0.0039 |
| ASSISTments2012 | +0.0184 | +0.0102 |
| Junyi2015 | +0.0111 | +0.0062 |

2. **96 条件机制排查（test_sim_con）**：六种对比学习变体（翻转/遮蔽 InfoNCE、投影头×2、预测一致性、证据加权一致性）在五套数据上均无稳定收益；**固定 0.95/0.05 软 Q**（不学习、无 CL）反而是收益最清楚的强对照（ΔAUC 最高 +0.0088，5/5 数据同向）。→ CL 路线需要换问题定义；Q 结构侧握着已证实的收益。

**本阶段（近两周）做了什么**：围绕"让 Q 侧与 CL 侧的机制可验证"设计了**十个创新方向**，全部实现并完成阶段 1 筛查实验（34 个训练条件 + 3 个规范化跳过，单种子 2026、40 epoch、Math1 + 合成数据、CPU），另建了两个可复用的评估工具（可辨识性探针、k-shot 分证据协议）。**所有结论为筛查级（单种子），用于定方向，不作为正式收益声明。**

## 三、重点展开：D2 有限 Q 编辑与题目作答-结构对比

### 3.1 要解决的问题

A1（可学习 Q）虽然预测更好，但学到的 Q 会**无差别稠密化**（硬密度 0.33–0.64，参考 Q 只有 0.01–0.30），且与参考 Q 的 F1 很低——Q 在"搬运总体答题表现"，而不是恢复题目真正的概念构成。D2 的想法：**给每道题一个"编辑预算"，让对比学习只在预算内选择"哪些 Q 关联值得修改"**。

### 3.2 机制（三个组件）

```text
① 统一编辑起点：P0 = 0.05 + 0.90·Q_ref（参考边=0.95，非参考边=0.05），S 初始化 = logit(P0)
② 软预算：E_j = Σ_k|Q_jk − P0_jk| / 0.90；L_budget = mean_j[relu(E_j − B)]²   （B=每题预算，起步 1）
③ 题目端对比：每题两组不相交学生 → 残差画像 ρ_ij = m_ij(y_ij − p̂_ij)（Rasch 教师去难度）
   → 小 MLP 出 K 维"作答视图"；结构视图 = normalize(q_j)（固定标准基，防止 Q 与原型共旋转）
   → InfoNCE：正对=同题两视图，负对=难度/作答量相近且参考标签不相交的题
总损失 = 预测 BCE + λq·弱先验 + λb·L_budget + λcl·L_RQ     （CL→Q 有直接梯度路径）
```

#### 3.2.1 组件①：为什么编辑起点是 P0 = 0.05 + 0.90·Q_ref，而不是之前的 0.55/0.45

旧初始化（参考边 0.55 / 非参考边 0.45）让所有边挤在 0.5 附近：①"非参考边"也带 0.45 权重，模型不改任何边就能靠这层背景通道传信息；②训练结束按 0.5 阈值切二值 Q 时大量边随机翻——无约束版 Q-F1 只有 0.437 的原因之一。D2 把"默认答案"设为 P0（参考边 0.95、非参考边 0.05），S = logit(P0) 作为可学习参数起点。

数值例子（K=5，某题标注概念 1 和 3）：

```text
Q_ref 行 = [1, 0, 1, 0, 0]  →  P0 行 = [0.95, 0.05, 0.95, 0.05, 0.05]
S 初始  = [+2.944, −2.944, +2.944, −2.944, −2.944]
```

0.95/0.05 不是 0/1：故意留一条窄通道让"参考标错了"的边仍能被证据扳回（weak supervision 本意），但偏离幅度由组件②管着。

#### 3.2.2 组件②：软预算在算什么（逐步数值例子）

编辑量 `E_j = Σ_k|Q_jk − P0_jk| / 0.90`：除以 0.90 表示"一条边从 0.05 完全反转到 0.95 记 1 个完整编辑单位"，即 E_j ≈ 这道题被改了几个完整边。惩罚 `L_budget = mean_j[max(0, E_j − B)]²` 只罚超额、平方增长（B 起步 1）。

同一道题（B=1，参考={1,3}）的三种状态：

| 状态 | Q 行假设 | E_j | 结果 |
| --- | --- | ---: | --- |
| 刚开始（=P0） | [0.95, 0.05, 0.95, 0.05, 0.05] | 0 | 不罚 |
| 小修正 | [0.90, 0.30, 0.90, 0.05, 0.05] | 0.33 | 预算内不罚——有证据的小修正自由 |
| 大漂移 | [0.10, 0.80, 0.90, 0.60, 0.05] | 2.39 | 超 1.39 → 罚 1.93，强力拉回 |

核心证据：无预算版 Q-F1 0.437（乱翻），加预算后 0.943 且 ACC 反而最高——"少改、按证据改，更准"。注意软预算只是惩罚不是硬上限，因此另报"真实跨越 0.5 的增删边数"。

#### 3.2.3 组件③：两视图怎么造、为什么这样造

**(a) 作答视图（证据侧）三步**：①去难度——残差 `ρ_ij = m_ij(y_ij − p̂_ij)`，p̂ 是 Rasch 教师（只用总能力 a_i 与题目难度 b_j）的预测；不去难度时画像最强信号是"这题难"，去掉后剩下的才是"哪类学生异常好/差"。②每 epoch 把学生对半随机分 U/V 两组各造一个视图——同题两份独立证据也要互相对齐，防记忆特定学生。③`[ρ, m]` 拼接过小 MLP 出 K 维——掩码必须输入，区分"没观察到"与"观察到且零残差"。

**(b) 结构视图（标注侧）**：`z_j^Q = normalize(q_j)`（当前可学习 Q 的行）。"固定标准基"= 概念 k 的坐标就是 e_k，不给 Q 配可学习原型——否则 Q 与原型可一起旋转成"题目 ID 编码"，对比损失被无意义满足；坐标钉死则语义钉死。

**(c) InfoNCE 规则**：正对 = 同题作答视图↔结构视图（U/V 各一次）；负对 = 参考标签不相交（防假负）且难度/作答量相近（堵难度捷径）的其它题。

**梯度路径**：`L_RQ → normalize(q_j) → Q → S` 是最短路径。直觉：若某题学生残差画像"像方程题"而结构视图指向"分式"，InfoNCE 推动 Q 行向"方程"转——即"作答证据选择哪些 Q 关联值得修改"。

#### 3.2.4 总损失分工与贯穿迷你例子

`L = BCE(预测) + λq·弱先验 + λb·L_budget + λcl·L_RQ`：BCE 管预测精度；弱先验把 Q 拉向 P0；预算限制总修改量；L_RQ 决定修改方向。四个项都对 Q 有梯度但分工不同。

**贯穿例子**：某题参考标注={分式}，而 U/V 两组学生中"方程好的人"在该题去难度残差都显著更高 → 组件③推动增加 Q 的"方程"边；组件②允许这种有证据的小修正（0.33 单位，不罚）但阻止全场大改；组件①保证参照系是 P0。最终 Q-F1 0.943：绝大多数边保持参考，少数边被证据移动，预测 ACC 全场最高。


### 3.3 结果与归因链（Math1，单种子）

| 条件 | test ACC | test AUC | Q-F1（与参考一致率） |
| --- | ---: | ---: | ---: |
| fixed_binary（固定参考 Q） | 0.7418 | 0.8331 | 1.000 |
| fixed_soft（同 P0 初始化、冻结 Q） | 0.7419 | 0.8335 | 1.000 |
| weakq_ctrl（0.55/0.45 可学习、无预算） | 0.7463 | 0.8376 | 0.437 |
| **d2_full（P0 初始化 + 预算 + 题目 CL）** | **0.7493** | **0.8384** | **0.943** |

**三条归因证据**：

1. **全场最佳 ACC 0.7493**（34 个条件第 1），比 weakq_ctrl 高 +0.0030；AUC 0.8384 也是全场最高——**ACC/AUC 双正，十个点里唯一**。
2. **同初始化归因**：fixed_soft 与 D2 同用 P0 初始化，但冻结 Q、无预算无 CL，ACC 只有 0.7419——P0 初始化本身让 ACC 下降约 0.0044；D2 从这个更差的起点反超到 0.7493，**预算 + 题目 CL 相对自身初始化基线的净贡献约 +0.0074**。
3. **预算确实在起作用**：Q-F1 = 0.943（learned 无约束版只有 0.437）——Q 被锚在参考附近做"少量、有据"的修改，同时预测反而最好。软预算的"少而准"设想得到数据支持。

### 3.4 为什么有效（机制解释）

- **预算约束 IRF 掩码不漂移** → 预测头 (θ⊙q − ψ⊙q) 的输入分布稳定 → ACC 直接受益；
- **对比对象从学生换成题目**：题目端 CL 对 Q 的梯度路径最短（L_RQ → z^Q=norm(q_j) → Q → S），不同于学生端 InfoNCE 的迂回路径（后者在 test_sim_con 中已证明无效）；
- **残差画像去难度**：作答视图用 Rasch 残差而非原始正确率，避免 CL 退化为"学题目难度"。

### 3.5 诚实的边界

- 单种子筛查；历史三种子实验中 Math1 ACC 的种子间标准差 ≈0.0013–0.0015，+0.0030 ≈ 2σ，**方向可信、量级需阶段 2 确认**；
- Math1 只有 20 题，题目端 InfoNCE 的负例池极小——**Math1 只是冒烟场，D2 的真正主场是 Eedi（948 题）/Junyi（500 题）**；
- synthetic 上为负（−0.05 AUC）：其参考 Q 被注入 20% 噪声，预算把 Q 锁向一个有噪参考当然受伤——见第五节的跨点发现②；
- 严格归因还差一个条件：同 P0 初始化 + 可学习 Q + 无预算无 CL（即统一基线 learned_no_prior），已列入阶段 2。

### 3.6 下一步（阶段 2，按优先级）

1. 补 learned_no_prior 条件，完成"初始化 / 学习 / 预算 / CL"四段归因；
2. Eedi、Junyi 三种子正式对照（题目端主场）；
3. 预算 B ∈ {1,2} 与 λb 小网格；报告 Q 增删边数、跨种子编辑一致率；
4. 若成立，与 D1/概念关系 CL 组合（预算约束"改多少"，关系 CL 约束"改出来的结构能否支持可重复的概念差异"）。

## 四、其余各点：一句话结论与关键数字

- **TRQ（信任域扰动一致性）**：把"固定软 Q 为什么有效"显式化为训练正则。Math1 Q-F1 +0.009~+0.014、ACC +0.0016；synthetic AUC +0.0058。对抗版（一步符号梯度）无效——阶段 2 只保留 random 版并做 exp/mask 单路径归因。
- **E3A（证据自适应锚定）**：k-shot 协议下 k=2 AUC **+0.0058**、k=5 +0.0023，但 **ACC 在 k=2 反而 −0.0024，NLL/Brier 全部 k 恶化**——收益只在排序层面，概率空间收缩破坏校准。修正方向：锚定移到 logit 空间、n0 按验证 NLL 选。其 k-shot 评估协议本身是本阶段最有复用价值的产出。
- **IPW-Q（可辨识性）**：预设判据"可学习 Q 使表示分离度下降 >20% 才启动约束"——实测方向相反（Sep +4.7%、IDS +6.8%），得到**确认性结论**：弱监督可学习 Q 不损害生成式诊断的可辨识性。直接支撑论文可靠性章节。
- **D5（非对称噪声后验）**：synthetic +0.0092（全场最大单点增益）；Math1 中性（参考可靠，无结构不确定性可利用）。边熵 0.26–0.32 表明 π 显著硬化，阶段 2 加结构 CL 时需防"提前硬化消除视图差异"。
- **D4（编辑效应）**：预测无变化，但 **sign_correct=0.627**（相关概念探针效应大于无关探针的比例）——模型存在中等程度的概念局部性，高于随机 0.5，作为模型行为分析素材。
- **D1/D3**：机制验证全部通过（关系对 122/batch 且梯度非零；G+U 分解误差 3.6e-07），但收益未现——原因主要是数据（Math1/synthetic 缺锚或缺"偏科群体"），换 Eedi 与定向合成后重测。
- **SACA**：归因相关 −0.12，方向学反——负结果如实保留；改排序式归因损失后再测。
- **ECW-Q**：三种经典统计量找噪声边的 AUC 全部低于预设 0.7 门槛（最好 0.665），按预设止损；其"置信度"思想并入 D2。

## 五、三个跨点发现（比单点结果更值钱）

1. **Math1 参考Q没有任何单概念题**（20×11、每题≥2 概念）→ D1/D3/D9 的"单概念锚"机制在 Math1 **结构性不可用**（结果目录各有 skipped.json 为证）。这不是实现问题，是数据集硬约束——锚依赖型方法必须去 Eedi/Junyi 验证。
2. **结构约束的收益方向取决于参考 Q 的可靠性**：预算在 Math1（可靠专家 Q）有益、在 synthetic（20% 噪声 Q）有害；ECW-Q 在噪声参考上找不出可信边。→ 统一教训：**对参考 Q 的约束强度应与参考置信度联动**。
3. **排序与校准是两个目标**：E3A 的 AUC +0.0058 伴随 ACC −0.0024 和 NLL 全线恶化。→ 选模指标必须同时含 AUC 与 NLL（已写入下一阶段协议）。
