# test_sim_con：Simple Contrastive 与软 Q 机制验证

实验状态：96 个正式条件已完成并通过 checkpoint 重放核验。正式目录为 [results/test_sim_con](../../results/test_sim_con/)；完整逐条件配对表见 [comparison.csv](../../results/test_sim_con/comparison.csv)，按验证集选模见 [selection.json](../../results/test_sim_con/selection.json)，方法级概览见 [method_overview.csv](../../results/test_sim_con/method_overview.csv)。以下数值均为三个训练种子的均值，增量为相同种子的配对差值。

## 协议与文件

- 五套已处理数据沿用原 train/valid/test；训练种子 2026、2027、2028。Math1 原始划分种子未知，其他数据的来源和划分见各数据目录。当前协议是**见过学生的作答预测**，不是新学生冷启动。
- 主训练预算统一为最多 60 epoch、patience 12、每种子按验证 AUC 留 checkpoint；ASSIST 另设最多 120 epoch、patience 20 的成对预算核验。共享模型参数为 alpha 0.8、嵌入维度 32、学生 batch 128、query 比例 0.25、主学习率 0.001、Q 学习率 0.005。固定 Q 的 lambda_q 和 lambda_coverage 均为 0；Weak-Q 两项均为 0.01。对比温度 0.2、视图噪声率 0.1，条件特有系数见各 manifest。

- comparison.csv 含 AUC、ACC、NLL、Brier、掌握表示有效秩、Q 密度和逐种子配对差值。各数据集的系数只按验证集选；测试指标只作选后报告。本轮是探索性方案排查，后续候选的设计曾参考早期测试表现，不能把同一批测试集上的发现当作独立确认。

遮蔽保持已答题正误，但不能保证掌握表示不变；同系数替换没有解决负收益。投影头的输入为最终掌握或隐式特征，均没有改善五套数据的预测。ASSIST 最终掌握投影组的表示有效秩从基线约 3.52 升到 8.60，测试 AUC 却下降 0.01544，说明单纯提高表示离散度并不足够。遮蔽视图监督 BCE 在 Eedi、ASSIST 的 AUC／ACC 有很小的同向收益，属于额外监督对照，不是对比学习收益。

无异人负样本的预测一致性使用完整 support 的停止梯度预测作为教师。系数 100 在多套数据出现早期崩塌；把系数降为 1 后，Math1 测试 AUC −0.000479、Junyi −0.000323，ASSIST 仅 +0.000022 且 ACC −0.001770。概念证据权重以固定参考 Q 计算两视图共同证据数，采用 n/(n+2)，系数 10；目前没有跨数据集收益。权重只是证据量代理，并非已校准置信度。

Math1 另将 alpha 从 0.8 改为 0.5：无辅助基线测试 AUC 从 0.834579 到 0.835613，但该 alpha 下原始 InfoNCE 相对配对基线仍为验证 AUC −0.000119、测试 AUC −0.000640、ACC −0.002475。分支权重改变没有救回原始对比目标。

## 固定软 Q 与 Weak-Q 的归因

固定软 Q 不学习关联：把参考 Q 的 1／0 分别替换成 0.95／0.05，阈值化后的 Q 仍等于参考 Q。下表是这个**全局固定配置**相对 A0 的 60-epoch 配对差值。共同候选 0.55／0.45 与 0.95／0.05 按五套数据平均验证 AUC 增量选择，分别为 +0.001230 与 +0.005576；0.95／0.05 被选中。逐数据集选参可能不同：Math2 的验证集选 0.8／0.2；Math1 以极小验证优势选 0.55／0.45，但其测试 AUC 下降。因此同时保留全局选择与逐数据集选择，不隐藏该差异。

**归因边界：**固定软 Q 是对照组，不是本工作的新模块。它没有学习 Q，也没有加入对比损失；其收益不能记为 Weak-Q 或对比学习的收益。它说明二值 Q 掩码的放松本身就可能改善预测。要证明“弱监督可学习 Q”的独立贡献，还需要在相同 0.95／0.05 起点下比较冻结与可学习 Q，并保持其余训练设置一致；当前 A1 从 0.55／0.45 初始化，不能直接用 A1 与本对照的差值完成这一归因。

| 数据集 | Δ验证 AUC | Δ测试 AUC | Δ测试 ACC | Δ测试 NLL ↓ | 有效秩 A0→软 Q |
| --- | ---: | ---: | ---: | ---: | ---: |
| Math1 | +0.000932 | +0.000577 | +0.001228 | −0.000615 | 3.01→2.57 |
| Math2 | +0.001198 | +0.001704 | +0.000909 | −0.002106 | 2.84→2.38 |
| Eedi | +0.007087 | +0.007683 | +0.005772 | −0.006199 | 4.68→2.18 |
| ASSIST2012 | +0.008795 | +0.008898 | +0.001933 | −0.005025 | 3.52→1.52 |
| Junyi2015 | +0.009869 | +0.008426 | +0.004259 | −0.008139 | 4.46→2.53 |

五套数据各有 3/3 种子测试 AUC 同向，Brier 也均降低。预测改善与有效秩下降同时发生，不能解释成知识点诊断更细或 Q 结构恢复。参考 Q 没有真值保证，Q-F1 只表示与参考矩阵一致。Weak-Q 的阈值化 Q 密度在 Math1／Math2／Eedi／ASSIST／Junyi 分别约为 0.526／0.639／0.350／0.331／0.315，而参考 Q 密度分别约为 0.305／0.203／0.040／0.010／0.026。移除 Weak-Q 的 soft-prior MSE 后五套数据的 AUC 差值仅万分之一量级；现有预测收益不能归因于该先验正则本身。

## 本轮结论与尚未验证的方向

- 原始学生 InfoNCE、遮蔽替换、投影空间、隐式分支投影、无异人负样本的一致性及概念证据加权版本，均没有在五套数据形成稳定且有实际幅度的对比学习收益。负结果保留，不把接近零的差值包装成创新。
- 固定 0.95／0.05 软 Q 是本轮收益最清楚的**归因对照**，不属于“弱监督可学习 Q＋对比学习”创新点。它也降低了掌握表示有效秩。下一轮应先固定相同 Q 初始化，比较冻结与可学习 Q 的独立增益，再研究受限的关联修正和诊断质量。
- 更广泛的独立划分或外部数据、已知真 Q 的合成任务、人工 Q 错误、真正新学生冷启动和更长预算的多数据复核仍是边界。本轮不据此宣称 Q 恢复、诊断真值改善或冷启动有效。
