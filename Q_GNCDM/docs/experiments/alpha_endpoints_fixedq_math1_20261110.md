# Math1：去除 Weak-Q 和 CL 后的 α 端点消融

实验 ID：alpha_endpoints_fixedq_math1_20261110；日期：2026-11-10。状态：三个 α × 三个训练种子，共 9 次训练完成。

## 本轮设置

固定原始二值参考 Q，不学习 Q、不进行软化；关闭 Weak-Q 先验、coverage、稀疏、二值化和全部对比损失。比较 α=0、0.8、1，唯一变化为学生掌握融合权重，各条件独立重新训练。

沿用 Math1 原 train/valid/test，种子 2026、2027、2028。最多 60 epoch，patience=12；每个种子只按验证 AUC 选模。embedding_dim=32，batch_students=128，query_fraction=0.25，lr=0.001；Q 学习率不生效，因为 Q 已冻结。训练 query 从学生与题目两侧证据中移除，验证及测试标签不输入编码器。

- α=0：仅隐式掌握；预测端仍使用固定参考 Q 掩码。
- α=0.8：20% 隐式＋80% 显式。
- α=1：仅显式掌握；学生掌握由固定 Q 和当前证据确定，但题目编码器、预测头仍训练。

完整配置、数据与代码哈希见 [manifest.json](../../results/alpha_endpoints_fixedq_math1_20261110/manifest.json)。其中历史配置保留 q_init_high/low 字段，但固定二值模式不使用该字段软化 Q；运行前已核验模型实际 Q 与二值参考矩阵完全相同。

三种子均值±样本标准差；Δ 为相对同种子 α=0.8 的差值，数值范围为 0–1。

| 0 | 0.824525 ± 0.007856 | 0.738140 ± 0.000960 | −0.010054 | −0.004930 | 0.489916 |

验证 AUC 均值依次为 0.825194、0.838962、0.837900。α=0.8 相对 α=1 的验证 AUC 平均高 0.001062，测试 AUC 高 0.002069，测试 ACC 高 0.002237（约 0.224 个百分点），NLL 低 0.002157。

三个种子的验证 AUC、测试 AUC、测试 ACC 均支持融合优于仅显式；测试 NLL 也一致改善。直接比较两个端点，α=1 相对 α=0 的 AUC 高约 0.007985、ACC 高约 0.002693。

## 与上一轮 Weak-Q 对照

以下差值统一为“α=0.8 融合 − α=1 仅显式”，两轮都没有 CL：

| Q 设置 | 融合带来的 Test AUC 增量 | 融合带来的 Test ACC 增量 |
| --- | ---: | ---: |
| 本轮：固定原始二值 Q | +0.002069 | +0.002237 |
| 上轮：0.55/0.45 初始化的可学习 Weak-Q | −0.000018 | +0.000257 |

上轮来源：[Weak-Q α 端点记录](alpha_endpoints_math1_20261110.md)。

因此，**不能说隐式掌握分支没有作用：在固定二值 Q 的当前协议中，20% 隐式分支提供了可重复的预测增量；在当前 Weak-Q 配置中，这个增量明显减弱。**

一种可进一步检验的解释是，可学习 Q 或 Q 的软化提供了原本由隐式分支承担的部分灵活性。但这仍是机制假设：两轮同时区别于 Q 是否可学习、是否软化、是否使用弱先验，不能单独把差异归因为“可学习 Q 替代隐式分支”。要区分这些因素，需要同一软 Q 初始化的冻结／学习对照，而不是凭本表直接下结论。

## 结论边界

- 本轮只证明 Math1、当前实现和固定训练预算下的增量，不证明所有数据集都如此，也未检验加入 CL 后的关系。
- α=0 的最佳轮次为 60、58、60；α=0.8 为 58、60、60；α=1 为 57、54、60。多组接近 60 轮上限，尚不是充分收敛比较。
- 不根据测试表现宣布 α=0.8 为所有系数中的最优值：本轮只比较三个事先指定的值。
- 固定 Q 下仅显式掌握的有效秩高于融合，但预测反而更差，再次说明有效秩不是越高越好，也不能替代诊断真值指标。
- 当前建议是保留隐式分支作为有效对照，不因上一轮 Weak-Q 结果直接删除它。
