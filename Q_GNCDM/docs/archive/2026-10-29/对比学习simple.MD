# Simple Contrastive Weak-Q G-NCDM 方案

## 1. 目标

本分支只验证一个最基本的问题：同一学生的作答记录经过少量答对／答错翻转后，认知表示是否应该保持接近，以及这种约束能否提升 Weak-Q G-NCDM 的响应预测。

第一版不加入证据增强、Jaccard、可靠负样本筛选、局部一致性、动态 Q 引导、投影头或对比预热。

## 2. 实验模式

| 模式 | Q | 噪声视图 | 对比学习 |
| --- | --- | --- | --- |
| A0 | 固定给定 Q | 无 | 无 |
| A1 | 可学习 Weak-Q，带弱监督 Q 损失 | 无 | 无 |
| S1 | 与 A1 相同 | 同一学生的低噪声视图 | 普通 InfoNCE |

核心比较：

- `A1−A0`：Weak-Q 本身的影响。
- `S1−A1`：简单对比学习的影响。

## 3. 正样本

作答向量采用项目原有编码：答对为 `+1`、答错为 `-1`、未作答为 `0`。

对学生原始训练证据 `x_i` 生成低噪声视图 `x_i+`：只在非零位置随机选择约 10% 的作答，将 `+1` 和 `-1` 互换，未作答位置始终保持 `0`。只要学生存在作答，至少翻转 1 条，避免两个视图完全相同。

正样本对为 `(x_i, x_i+)`。它表达的假设是：少量偶然答错或猜对不应彻底改变学生的整体认知状态。

## 4. 负样本

一个 batch 内的不同学生互为负样本。对学生 `i`，正样本是其自身噪声视图，其他学生 `j != i` 的噪声视图均为负样本。

第一版不筛选负样本。随机负样本可能包含认知状态相近的学生，但这是验证基础框架时可以接受的简化；只有 S1 有效后才需要研究更精细的负样本。

## 5. 表示和损失

干净视图与噪声视图经过同一个 Weak-Q G-NCDM，得到最终认知状态：

```text
theta_i       = diagnose_theta(x_i)
theta_i_noise = diagnose_theta(x_i_noise)
```

第一版不增加投影头，直接对 theta 做 L2 归一化，以余弦相似度和温度 `tau=0.2` 计算双向 InfoNCE：

```text
L_total = L_response + L_weak_Q_and_regularization + lambda_cl * L_InfoNCE
```

默认 `lambda_cl=0.01`。响应预测损失只使用干净视图，噪声视图只参与对比损失，避免把普通噪声训练的收益误算成对比学习收益。

## 6. 数据安全约定

训练时从每名学生的训练作答中抽取 query。query 答案会同时从学生行输入和题目列输入中删除，模型只根据剩余 support 预测 query。噪声只能施加在 support 的已作答位置，不能接触 query、验证集或测试集答案。

验证和测试仅用于评价；最佳 checkpoint 按验证 AUC 选择。

## 7. 默认设置

```text
alpha = 0.8
positive_noise_rate = 0.10
temperature = 0.20
lambda_cl = 0.01
batch_students = 128
seeds = 2026, 2027, 2028
```

第一轮固定这些参数，不进行大规模搜索。主要报告 test AUC 和 test ACC，同时保存 RMSE、Brier、NLL 和 learned-Q 与参考 Q 的 F1。

## 8. 同学生高噪声负样本

暂不纳入 S1。后续可以增加 S2：对同一学生翻转例如 40% 作答，作为额外负样本。这相当于学习“低噪声保持不变、高噪声必须远离”的鲁棒半径，假设比普通实例对比更强，也可能产生矛盾，因此必须作为 S1 之后的独立消融，而不能和基础框架同时引入。

## 9. 第一版验收标准

- A0、A1、S1 使用相同划分、训练种子和评价代码。
- 噪声只翻转非零作答，query 不进入任何诊断输入。
- S1 的对比损失和梯度有限，A1 的对比系数严格为零。
- 至少运行 3 个训练种子并报告均值与样本标准差。
- 只有 `S1−A1` 同时在 AUC/ACC 或概率误差上形成一致改善，才能认为简单对比框架出现正向信号。
