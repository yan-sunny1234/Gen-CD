## 一、当前模型的问题与设计边界

### 1.1 从原始 G-NCDM 到当前 Weak-Q

原论文的 G-NCDM 用固定专家 Q 参与显式掌握生成和响应预测掩码；对应正文式（33）、（36）、（37）。本文以其公开版本及作者代码为依据，不把尚未核实的正式刊会归属写成事实。[原论文](https://arxiv.org/html/2507.09831v1)、[作者代码](https://github.com/CSLiJT/Generative-CD)。

以下公式按**当前本地实现**记号书写，不是声称与论文的每个预处理细节相同。令学生、题目、概念数分别为 N、J、K，已观察掩码为 m，二值正确标签为 y：

\[
R_{ij}=m_{ij}(2y_{ij}-1).
\]

所以 R 的 −1、0、1 分别为错误、未观察、正确。未观察不是答错。

\[
Q=\sigma(S),\quad
\theta_i^{exp}=\sigma(R_iQ/\sqrt K),\quad
\theta_i=(1-\alpha)f_\phi(R_i)+\alpha\theta_i^{exp}.
\]

当前主要实验取 \(\alpha=0.8\)。Q 还进入预测：

\[
p_{ij}=\operatorname{NCD}
\left(A_\theta(\theta_i\odot q_j)-A_\psi(\psi_j\odot q_j)\right),
\quad \psi_j=g_\omega(R_{\cdot j}).
\]

这意味着：Q 不只是可视化标签，同时改变“如何汇总学生证据”和“如何预测一道题”。新方案应明确作用哪条路径。相关实现见 [Weak-Q 模型](../../models/weak_q_gncdm.py)、[现有对比模块](../../simple_contrastive.py)、[训练入口](../../experiments/run_simple_contrastive.py)。

本文的 support 指“本次允许输入模型的作答证据”，query 指“本次隐藏、只用于预测监督的作答”；它们可以是正式训练集内部的划分，不等于正式 test。前四个方向的 \(L_{weakQ}\) 默认指当前 soft-prior MSE，即 \(\operatorname{mean}(Q-P^0)^2\)，若改为其他弱标签损失需单独记录。本设计的新共同基线明确设 lambda_coverage=lambda_sparse=lambda_binary=0，并在 manifest 固定；不是在方法组单独删除旧项。若后续保留 coverage，则同结构有／无 CL 对照必须同时保留相同系数。记该轮完整共同损失为 L_base；前四条公式中的预测＋弱先验就是本建议下的 L_base，任何额外旧项均应显式记录。

### 1.2 本轮方案必须回应的已有证据

依据 [test_sim_con 正式记录](../experiments/test_sim_con.md)，现有随机翻转、简单遮蔽、投影头、预测一致性和证据计数加权一致性，均没有提供足够稳定的模块收益。不能换一个名称，把相同损失再作为新机制提出。

几个具体问题比继续扩大系数网格更值得解决：

- **目标错位。** 原 InfoNCE 让同一学生两视图接近，让所有不同学生分开。认知诊断需要相同知识状态具有相近解释，不需要尽可能识别学生身份。
- **增强语义不稳。** 错误改正确可能改变该概念的证据；一律拉近会与预测监督冲突。题目很少时，“较低比例噪声”也可能被取整为翻转一题，实际扰动并不小。
- **Q 可以走捷径。** 通过把很多原本为零的边抬高，模型可能传递总体答题表现，而没有恢复题目真正需要的概念。
- **旧配置并没有启用全部正则。** 虽然模型类提供 sparse、binary 项，正式 simple runner 将两项系数设为零。0.55/0.45 初始化且 K≥3 时，行和已经超过 1，coverage 项初始就为零。不能把这一配置称为“有严格稀疏结构约束”。
- **CL 不一定直接训练 Q。** 最终掌握上的 CL 能进入显式 Q 路径；只对隐式分支投影做 CL，则没有直接的 Q 梯度。必须实际检查计算图。
- **高 AUC 不等于准确诊断。** 真实参考 Q 没有真值保证；与参考 Q 的 F1 不是“真实 Q 恢复率”。有效秩也不是越高越好。

已有 A1 与固定软 Q 的初始化不同，所以不能从两者直接相减得到“学习 Q 的贡献”。后续统一从相同 Q 起点做冻结／学习、无 CL／有 CL 的交叉对照。

### 1.3 五个方向共同保留的原则

1. Q 仍可学习，并保留弱先验或显式观测 Q 的概率模型。研究问题是“作答证据怎样修正 Q，CL 怎样帮助这种修正”。
2. 不把当前 Q 自己定义的关系当成已知真关系；采样依据优先来自独立训练证据及冻结参考锚点。
3. 不把全体参考零边当成可靠负标签。参考 Q 的零可能是漏标。
4. 不强制不同知识点统计独立。概念本来可能相关。
5. 每个方向先有无 CL 的同结构版本，再加入 CL；否则无法归因。
6. “可能创新”不等于“已经首创”。以下贡献表述均是待验证假设，最终还需要按最终实现重新检索最近邻工作。

## 三、方向一：跨证据的概念关系对比

### 3.1 一句话想法及例子

**用一部分答题证据判断“两个学生在某个概念上是否相似”，用另一部分证据产生诊断表示，再要求这个关系能复现。**

例如甲、乙总成绩接近，甲在“函数”题上明显更好，在“几何”题上反而更差。整个人向量上的一个余弦值不能准确表达这两个相反关系。应在函数维比较函数，在几何维比较几何；总成绩相近不是正例条件，也不是负例条件。

这个方向首先改变**监督语义与样本关系**，不增加大编码器，不增加 LLM，不先加投影头。

### 3.2 来源、最近邻与候选创新

SCD 已有跨视图自监督，DCD 已有弱标签概念对齐，PLCD 已有过程级对比。因此不能把“概念级 CL”四个字作为贡献。

可研究的差异是：**在生成式诊断中，以独立作答证据建立总体表现条件下的概念关系，作用于由可学习 Q 生成的诊断坐标，检验这种关系监督是否使 Q 的修正更可靠。**假负样本是已知问题；这里的新假设是用认知诊断特有的“同概念、相近总表现、可重复的证据差异”处理它。[假负样本的通用研究](https://papers.neurips.cc/paper_files/paper/2020/hash/63c3ddcc7b23daa1e42dc41f9a44a873-Abstract.html)。

### 3.3 最小实现：两份证据，先不做三视图

每个训练 episode 先保留原来的监督 query H，并从学生和题目两侧输入中删除 H。再将 support 随机分为 A、B：

- A：产生掌握表示 \(\theta_i^A\)。
- B：只建立正负关系，关系掩码停止梯度。
- 交换 A、B 再计算一次，使结果不过度依赖某一次拆分。
- 主 BCE 仍使用完整 support \(A\cup B\) 预测 H。

这样只用两份内部证据，不需要“同人两个视图再加第三份标签证据”。初版正例可以是**不同学生**；不要求正例只能是自己。

概念锚题集合 \(E_k\) 来自冻结参考 Q。优先使用概念标签较明确、具有足够作答的题目；多概念题初版可以降权。它们只是“相对可信锚点”，不能自动称为专家真值。若数据集没有足够可信锚题，该方向应报告不可充分识别，而不是强行生成标签。

### 3.4 怎样判定正例和负例

先用训练内部的一个简单总体模型估计：

\[
\widehat p^g_{ij}=\sigma(a_i-b_j).
\]

其中 \(a_i\) 是总体表现代理，\(b_j\) 是题目难度。它只是去除显而易见的总分／难度影响的工具，不是已知真实能力。对当前概念 k，计算 A←B 关系时，a 优先只由 B 中不属于 k 锚题的记录估计，再在 k 的锚题上计算残差；可记为 \(a_i^{(-k),B}\)。不得用 A 或 A∪B 估计它。若 B 几乎只有概念 k，用同批答案拟合能力会使残差均值被评分方程压到近零，此时应跳过，而非强行生成关系。互换方向同理；题目难度遵守第八节的交叉拟合规则。

在 B 证据上构造概念残差代理：

\[
t^B_{ik}=
\frac{\sum_{j\in B_i\cap E_k}w_j(y_{ij}-\widehat p^g_{ij})}
{\epsilon+\sum_{j\in B_i\cap E_k}w_j}.
\]

第一版 \(w_j=1\)，不要同时学习题权。为每个概念状态估计区间 \(I^B_{ik}\)，可从训练题目重采样得到；样本少时区间不可靠，应跳过，而不是硬说“已校准”。设总体表现匹配阈值为 \(\delta_a\)，概念相似容忍度为 \(\delta_p\)，可区分差距为 \(\delta_n>\delta_p\)。

对学生 i 的概念 k：

- 候选池先要求概念相同、总体表现相近、有效答题数相近。
- **正例**：差值 \(t^B_{ik}-t^B_{uk}\) 的区间整体位于 \([-\delta_p,\delta_p]\) 内。
- **负例**：该差值区间整体位于 \(\delta_n\) 右侧或 \(-\delta_n\) 左侧。
- **其余**：未知，不参与这一项损失。

仅仅“两区间有重叠”不足以证明相似：区间很宽时，几乎人人都重叠。使用“差异足够小”的证据，比“未能证明有差异”更保守。

初版若 bootstrap 成本较高，可用足够证据量条件下的分位组做探索代理，但必须标记为近似，并用独立 B／A 重复一致率检查配对可靠性。不能将所有中间组都归负样本。

### 3.5 表示、相似度与损失

直接利用现有可学习 Q 生成的概念坐标，先不新增向量投影：

\[
x^A_{ik}=\theta^A_{ik},\qquad
s_k(i,u)=-\frac{(x^A_{ik}-x^A_{uk})^2}{s_k^2+\epsilon}.
\]

右侧 \(s_k^2\) 是无 CL 训练阶段估计并冻结的尺度，实施时变量命名为 scale_k，避免与相似度函数重名。也可初版统一为 1，再用温度控制尺度。只比较同一个概念，避免一维余弦相似度退化为几乎恒定值。

多正例损失：

\[
L_{rel}^{A\leftarrow B}
=-\frac1{|\mathcal V|}
\sum_{(i,k)\in\mathcal V}
\frac1{|P^B_{ik}|}\sum_{u\in P^B_{ik}}
\log
\frac{\exp(s_k(i,u)/\tau)}
{\sum_{v\in P^B_{ik}\cup N^B_{ik}}\exp(s_k(i,v)/\tau)}.
\]

\(\mathcal V\) 只包含同时有正例和负例的学生—概念。排除自身，按有效项数平均；无有效项时返回可导的零并记录覆盖率。

\[
L=L_{pred}+\lambda_qL_{weakQ}
+\frac{\lambda_{cl}}2
(L_{rel}^{A\leftarrow B}+L_{rel}^{B\leftarrow A}).
\]

Q 的梯度通过 \(\theta^A\)／\(\theta^B\) 的显式聚合进入；**采样标签不从当前 Q 接收梯度**。初版保持现有 \(\alpha\)，不要同时修改分支融合。

### 3.6 开发步骤与伪代码

1. 新增 support 二分与 train-only 关系构造函数；先输出覆盖率，不训练。
2. 用当前无 CL 模型计算 \(\theta^A,\theta^B\)，验证正负关系确实具有可重复性。
3. 加入关系损失，检查 Q 梯度非零，关系掩码无梯度。
4. 固定 Q 版本与可学习 Q 版本都运行，主预测协议不变。
5. 只有确认关系可用后，才考虑更细的动态 Q 局部池化；首版不需要它。

~~~python
support, query = make_episode(train_only)
A, B = split_support(support, seed)
pairs_B = build_pairs(evidence=B, reference_q=Q0, teacher=frozen_teacher)
pairs_A = build_pairs(evidence=A, reference_q=Q0, teacher=frozen_teacher)
theta_A = model.diagnose_theta(A)  # 内部使用可学习 Q
theta_B = model.diagnose_theta(B)
cl = 0.5 * (relation_nce(theta_A, pairs_B) + relation_nce(theta_B, pairs_A))
loss = prediction_bce(support, query) + weak_q_loss() + lambda_cl * cl
~~~

### 3.7 必要消融及判据

| 对照 | 检验什么 |
| --- | --- |
| 同结构 Weak-Q，无 CL | 新 CL 的净贡献 |
| 原学生 InfoNCE | 是否真正解决学生身份目标错位 |
| 概念关系但不匹配总体表现 | 是否只是学总分分组 |
| 同份证据定标签并编码 vs A／B 独立 | 是否自我证明、过拟合配对规则 |
| 固定 Q vs 学习 Q；CL 路径 Q.detach | 收益是否需要 CL 直接改善 Q |
| 同样伪标签的普通回归或成对排序 | 收益来自对比形式，还是额外关系监督 |
| 打乱概念关系 | 语义是否真的有用 |

**先试数据：**合成数据检查真概念差异；再用 Eedi 或 Junyi 的高证据学生做可行性检查。Math1／Math2 题目很少，A／B 拆分后单概念证据可能不足，不能因为矩阵稠密就假定适合此方案。ASSIST 应单独报告低证据学生覆盖率。

**支持该创新的证据：**验证集预测不劣且概念关系跨证据复现改善；已知真 Q／真掌握的模拟中出现结构或诊断收益；CL→Q 阻断后收益减弱。

**停止条件：**有效配对覆盖率极低；收益只出现在头部学生；普通关系回归已获得全部收益；或提高概念分组指标却损害预测与校准。出现这些情况应缩小结论，不能硬称对比学习有效。

<a id="direction-2"></a>

## 四、方向二：有限 Q 编辑与题目作答—结构对比

### 4.1 一句话想法及例子

**让一道题的作答证据与它的概念结构互相核对，用编辑量的软预算惩罚抑制无差别的大规模修改。**

例如某题原来标“分式”，独立学生群体的表现却更像“方程”题。在保留原结构约束的前提下，对比学习可以支持增加方程关联；若所有题都因正确率相近而相似，则应被难度控制和假负样本检查识别出来。

CL 的对象从学生转为题目，对 Q 的作用更直接。这一方向最适合形成“结构学习＋对比证据”的统一主线。

### 4.2 想法来源与创新边界

DCD 已单独建模题目标签分布；正则化 Q 校验已有长期研究；2026 年 Q 原型对比预印本也表明“原型＋Q＋CL”的宽泛组合并不新。

候选创新应限定为：**对现有弱 Q 的有限编辑，以独立作答证据和结构表示的匹配来选择；区分行为难度相似与概念关联相似，并验证 CL 确实改善具体补边／删边。**这是可检验的完整机制，不是单独一个正则项。

### 4.3 首版直接约束实际编辑量，不先加门控网络

统一初始化为：

\[
P^0=0.05+0.90Q^0,\quad Q=\sigma(S),\quad S^{init}=\operatorname{logit}P^0.
\]

保留当前 Q 参数化，定义每题的软编辑量：

\[
E_j=\sum_k\frac{|Q_{jk}-P^0_{jk}|}{0.90},
\]
\[
L_{budget}=\frac1J\sum_j[\max(0,E_j-B_j)]^2,\qquad
L_{edit}=\frac1{JK}\sum_{jk}|Q_{jk}-P^0_{jk}|.
\]

一次从 0.05 到 0.95 的完整反转对应一个单位编辑量；很多微小修改也可能累积成同样的量。B 是**软预算目标**，有限罚项不保证实际不超预算，更不等于硬修改了几条边。应另报超预算比例、超额和跨越 0.5 的真实增删边数。若将来需要硬上界，需使用投影或受约束参数化，单列实验。

初版先固定预算，使用弱先验＋预算损失＋CL；将额外 L_edit 的系数设为零即可，避免弱先验、编辑 L1 和预算三重叠加把 Q 锁死。之后再单独消融 L1。预算可从每题 1、2 个等效完整编辑量开始，按验证集选择。

**为什么不先加入 G 门控：**另一种表示是 \(Q=(1-G)P^0+G\,V\)。但若初始化 V=P0，门控初始梯度为零；V 的梯度又乘以 G。大 K 下为满足预算把 G 设得很小，会明显拖慢 Q 学习。因此门控只作为后续可解释编辑选择的扩展，不作为首版必要条件。

另一个容易犯的错误是有界 logit 残差：
\[
Q=\sigma(\operatorname{logit}P^0+\delta\tanh\Delta).
\]
若 \(\delta\le\log19\)，从 0.95/0.05 出发不能实现真正越过 0.5 的结构反转（边界时最多逼近或达到阈值，取决于参数化）。这样的实现只能称关联重加权，不能宣传为补边删边。

### 4.4 作答视图怎样做，避免只学题目难度

为每道题划分两组**不重叠的训练学生** U、V，使用与预测 query 不重叠的证据，构造：

\[
z_j^{R,U}=\operatorname{norm}\left(
r_\phi([\rho_{\cdot j}^{U},m_{\cdot j}^{U}])
\right),\quad
\rho_{ij}=m_{ij}(y_{ij}-\widehat p^g_{ij}).
\]

r 是新建的题目相关性头，不直接把现有 \(\psi_j\) 当成概念向量：\(\psi_j\) 原本用于难度建模。观察掩码必须输入，缺失值不能被当成零残差的“完美预测”。

可实现的首版是长度为 N 的残差与掩码拼接，经过一个小 MLP 输出 K 维。每轮重划 U／V，降低固定学生 ID 群体捷径的风险；这仍不能排除题目缺失模式记忆，应做掩码单独输入的对照。它沿用当前矩阵模型的维度条件，不声称能自动处理任意新学生数。

使用原始作答画像的版本作为对照；残差画像是本方向的机制要素，但必须单独消融。难度模型的来源严格按第八节处理。

### 4.5 结构视图、正负样本和相似度

第一版固定概念原型 \(c_k=e_k\)，即 K 维标准基：

\[
z_j^Q=\operatorname{norm}\left(\sum_kQ_{jk}c_k\right)
=\operatorname{norm}(q_j).
\]

这样语义坐标固定，不给 Q 和任意可学习原型一起旋转成题目 ID 编码的机会。固定坐标不等于要求学生概念统计独立。

- 正对：同一道题的作答视图与结构视图。
- 负对：难度、作答量相近，但冻结锚标签明确不相交的其他题。
- 参考标签相同或高度重合的题：从负集合移除，必要时作为多正例，但初版先移除。
- 未标注或标签冲突的题：未知，不能自动算负。
- 相似度：归一化向量的余弦。

\[
L_{RQ}=-\frac1{2|\mathcal J|}
\sum_{j\in\mathcal J}\sum_{v\in\{U,V\}}
\log
\frac{\exp(\cos(z_j^{R,v},z_j^Q)/\tau)}
{\exp(\cos(z_j^{R,v},z_j^Q)/\tau)
+\sum_{\ell\in N_j}
\exp(\cos(z_j^{R,v},z_\ell^Q)/\tau)}.
\]

\[
L=L_{pred}+\lambda_qL_{weakQ}
+\lambda_eL_{edit}+\lambda_bL_{budget}
+\lambda_{cl}L_{RQ}.
\]

主任务和 CL 使用同一个 Q；CL 有明确路径
\(L_{RQ}\rightarrow z^Q\rightarrow Q\rightarrow S\)。

### 4.6 防止模型互相迁就

作答头和 Q 同时自由训练，可能一起学出任意编码。初版采取三个约束：

1. 固定概念坐标；预算限制 Q 偏离；保留弱锚定。
2. 作答头先用训练锚题的参考概念做短期多标签预训练，再联合训练。预训练是否启用是一个配置项；所有同结构对照必须得到完全相同的预训练。
3. 固定一批未参与相关性头拟合的训练内学生，用预先定义的结构—行为一致性统计检查 Q，例如由其他题形成概念残差，再检验其对目标题残差的增量解释；目标题从概念证据中排除，统计规则事先固定。这项核验不经过相关性头。固定 N 维 MLP 中，这批学生对应的输入列权重未被训练，不能直接把他们送入该 MLP 宣称新学生泛化。若要编码任意新学生集合，应另行使用共享参数的集合编码器。

预训练不是必需的新模块：若无预训练的简单版本已稳定，优先保留简单版本。若它贡献明显，需单独比较“相同预训练＋普通多标签 BCE”，否则不能把全部收益归 CL。

对于多概念题，不使用“每题只能选择一个概念”的单标签 softmax。未来若加入题目—概念原型边级损失，应使用多正例或逐边监督，且构造概念行为原型时排除当前题，防止自匹配。

### 4.7 最小实验与失败判据

先在 Eedi／Junyi 做题目端实验：题目数量足够，容易构成负例池。Math1 仅 20 题、Math2 仅 16 题，不适合把大批量题目 InfoNCE 当首个验证场景。

逐步执行：

1. 只加编辑参数化和预算，CL=0，确认预测与 Q 的变化。
2. 冻结 Q，仅训练相关性头：确认行为画像确有概念信息。
3. 预算 Q＋跨视图 CL。
4. 阻断 CL→Q，但保留主任务对 Q 的梯度。
5. 同样信息、同样相关性头改用多标签 BCE／结构重建。
6. 去预算、打乱题目配对、取消难度匹配、原始画像替代残差，各作为单独消融。

**核心指标：**除 AUC、ACC、NLL、Brier 外，报告 Q 增删边数、总质量与硬密度、跨种子编辑一致率、不同噪声类型的边恢复、独立学生上的题目概念识别。硬阈值应预先固定或只用验证／合成验证选取。

**支持创新：**CL 比同信息 BCE 更有效；预算防止无差别稠密化；Q 的改善可在独立作答与合成真 Q 上复现；阻断 CL→Q 后结构收益消失或减小。

**停止条件：**只有作答头准确率上升，Q 与预测无改善；Q 只编码题目身份；随机配对仍有相同收益；或低维语义结构与难度无法区分。此时最多能称题目表示正则化，不能称对比驱动 Q 修复。

## 五、方向三：保留总表现的概念残差对比

### 5.1 一句话想法

**预测仍然使用全部合法信息，但 CL 只比较“超出总体表现预期的概念差异”，避免对比目标主要变成总分排序。**

方向一改的是“谁和谁比较”；方向三改的是“比较什么量”。两者可以独立消融，也可能最终组合。不能把这两项写成两个同义名称。

### 5.2 从本项目得到的明确动机

固定软 Q 有精确分解：

\[
Q_\varepsilon=(1-2\varepsilon)Q^0+\varepsilon\mathbf1_J\mathbf1_K^\top,
\]
\[
RQ_\varepsilon=(1-2\varepsilon)RQ^0+
\varepsilon(R\mathbf1_J)\mathbf1_K^\top.
\]

第二项把一名学生的**净正确数**复制到每个概念。它同时受正确率、作答数、题目难度和选题分布影响，不能直接称为真实总能力。0.95/0.05 对应概念项系数 0.9、共同项 0.05；0.55/0.45 对应 0.1 和 0.45。

预测端也有：
\[
\theta\odot q_j^\varepsilon
=(1-2\varepsilon)(\theta\odot q_j^0)+\varepsilon\theta.
\]

因此软化 Q 不只是“让边更平滑”，还打开了背景信息通道。这是严格代数事实；但它是不是全部实测收益的原因，需要两条路径的消融，不能仅靠公式下结论。

上述等式针对当前**未按题量归一化**的聚合。若以后改成加权平均，需重新推导，不能直接照搬。

### 5.3 为什么还有创新空间

“总体能力＋特定技能”“概念解耦”都已有研究。DCD 已做概念因子学习，[Coral，NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/013f9cd52b38e3e53475605d2b8e7c23-Paper-Conference.pdf)也涉及解耦与协同表示。

本方向的具体假设是：**针对 G-NCDM 软 Q 的共同信息通道，在保持原预测映射的条件下，重新定义 CL 的输入，使它提供概念特异的 Q 梯度，而不消除预测有用的总体表现。**这比“增加解耦模块”更具体，也更容易通过等价性核验和梯度归因证伪。

### 5.4 先做精确等价分解，不贸然重写主干

用训练内部总体模型给出 \(\widehat p^g_{ij}=\sigma(a_i-b_j)\)，并停止其梯度。定义：

\[
U_{ik}=\frac{2}{\sqrt K}\sum_jm_{ij}q_{jk}
(y_{ij}-\widehat p^g_{ij}),
\]
\[
G_{ik}=\frac1{\sqrt K}\sum_jm_{ij}q_{jk}
(2\widehat p^g_{ij}-1).
\]

严格有：

\[
G+U=RQ/\sqrt K.
\]

于是主预测仍使用：
\[
\theta_i=(1-\alpha)f_\phi(R_i)+\alpha\sigma(G_i+U_i).
\]

这里 G 是“由总体表现／难度模型解释的期望项”，U 是剩余证据项。两者都可以依赖概念 k 的题目组成；不是两个已被唯一识别的心理潜变量。

**关键好处：**关闭 CL 时，给定相同参数与输入，预测与原模型数值一致；不因残差化而丢失信息，也不改变原掌握生成器的单调性。先检验等价，再训练，能避免把参数化错误误当新收益。

### 5.5 CL 用什么残差，怎样构造关系

为了减少证据量差异，CL 可使用归一化残差均值，而主预测仍使用上面的精确 U：

\[
z^A_{ik}=
\frac{\sum_{j\in A_i}q_{jk}
(y_{ij}-\widehat p^g_{ij})}
{\kappa+\sum_{j\in A_i}q_{jk}}.
\]

\(\kappa>0\) 是固定平滑量，首版取一个小常数并报告。CL 比较的是相对强弱，不是绝对掌握；\(z=0\) 仅表示接近总体模型预期。

使用方向一的距离型概念关系损失，将 \(\theta^A_{ik}\) 替换成 \(z^A_{ik}\)。保持**完全相同的配对规则、温度候选和训练预算**，才能判断残差表示是否有用。这个对照在方向三内部重跑：θ 与 z 共享同一 C／A／B、能力估计、有效样本、正负集合和训练 query。方向一原始二分结果只能作外部参考，不能直接相减归因于表示选择。不要把标量送进余弦 InfoNCE；标量归一化后几乎只剩正负号。

为防止两个视图因分别拟合能力而换了坐标，建议：

1. support 分成 C、A、B。
2. C 只估计这一学生的 \(a_i\)，题目 \(b_j\) 来自其他学生折。
3. A 计算残差表示，B 建立同概念正负关系；交换 A／B。
4. 两个方向共享 C 得到的总体表现估计。
5. 主 BCE 仍使用 \(C\cup A\cup B\)，没有证据做 CL 的学生照常参加主训练。

起步可按 C:A:B=20%:40%:40% 划分，但这只是建议起点，必须看有效概念覆盖率。不能为满足比例而复制同一作答到多个集合。少题数据可能不适合三分，应如实报告，并以方向一或其他路线为主。

### 5.6 Q 怎么得到新信号

若总体模型、尺度和配对全部停止梯度，残差 CL 的可训练参数主要是 Q：

\[
L_{res}\rightarrow z^A\rightarrow Q.
\]

它不直接训练原隐式学生编码器 \(f_\phi\)。这应被明确称为**残差驱动的 Q 正则**，不是声称所有编码器都获得了新对比监督。

Q 可能通过降低全部权重、扩大不相关覆盖等方式改变残差尺度。需要保留弱先验并监测 Q 总质量；尺度不由模型自由增大。若后续加入方向二的编辑预算，应作为新实验，不要首版同时打包。

证据量筛选也不能只用：
\[
n_{eff}=\frac{(\sum q)^2}{\sum q^2+\epsilon}.
\]
一批极小而相等的 q 也可能得到很大的有效样本量。还需检查参考锚题数和总权重下限；筛选依据停止梯度。n_eff 是证据量代理，不是校准置信度。

### 5.7 最小实施步骤

1. 在模型旁增加分解函数，返回 G、U、残差均值，原 diagnose_theta 接口保持兼容。
2. 核验所有学生的 \(G+U\) 与原 \(RQ/\sqrt K\)，以及关闭辅助项后的预测一致性。
3. 加训练内总体模型与 C／A／B 划分；先看残差是否跨 A／B 可重复。
4. 使用方向一已经核验过的关系损失，仅替换输入量。
5. 记录 CL 对 Q 的梯度与主 BCE 对 Q 梯度的夹角，检查是否长期严重冲突。

如果 Q 固定、其他辅助参数也固定，残差 CL 没有可更新参数；应在小规模检查中确认这一事实，不必重复运行一个实际上等价的完整训练。它能直接证明该首版的作用路径是 Q。

### 5.8 必要对照、成功与失败

| 对照 | 作用 |
| --- | --- |
| 原模型 vs G＋U 分解、CL=0 | 数值等价性，排除重写主干的干扰 |
| 同一关系损失作用于 θ vs 残差 z | 表示选择的净贡献 |
| 原始净作答聚合 vs 难度校正残差，使用同一平滑量及加权分母 | 残差化的净贡献，避免同时改变归一化 |
| 能力匹配 vs 不匹配 | 是否仍只在区分总表现 |
| 残差 CL vs 同关系普通排序 | CL 形式是否必要 |
| Q 只用于生成／只用于预测／两处均学习 | 软 Q 背景通道在哪一处产生收益 |

**优先数据：**Eedi／Junyi 的较充分证据样本；合成数据人为设置“总表现接近、概念偏科相反”的学生组，是验证核心假设最直接的场景。

**支持创新：**相比完全相同配对下的 θ 对比，残差对比更能识别概念偏科，并改善 Q 或独立预测；其梯度不是只把每题所有 Q 边一起抬高。

**失败情形：**Rasch 代理过于粗糙，残差主要代表模型误设；残差不跨证据复现；CL 只学题目曝光偏差；或需要丢弃大多数学生才有效。不能把残差趋零解释为掌握提高。

若后续确需将 a 直接送入预测头，例如 \(\ell_{ij}=\ell^{GNCDM}_{ij}+\beta_j a_i\)，这是额外架构改动，必须单列“增加 a 通道但无 CL”对照，不能再称为等价分解。

## 六、方向四：概念局部的作答编辑效应对比

### 6.1 一句话想法与例子

**不要求改答案前后掌握完全相同，而要求一次证据变化对相关题和无关题的影响有合理区别。**

例如把一条“分数计算”的错题证据改成对，模型对其他分数题的预测应比对无关几何题更敏感。比较的对象是“模型怎样响应证据变化”，而不是学生向量本身。

这只是**作答证据编辑效应**，不是证明一次教学干预导致真实能力变化。合成编辑不会产生新的真实标签。

### 6.2 为什么原始单调约束不够

当前学生编码器使用非负有效权重，Q 也非负。因此输入逐坐标增大时，\(\theta\) 不会下降：

\[
R^+\ge R^-\Rightarrow\theta(R^+)\ge\theta(R^-).
\]

直接增加 \(\operatorname{ReLU}(\theta(R^-)-\theta(R^+))\) 在此架构中恒为零。显式分支线性输入的单题变化又直接与该题 Q 行成比例，用当前 Q 当目标会循环自证。

CMCD 已研究翻转作答与单调关系；[ID-CDM，WWW 2024](https://arxiv.org/html/2309.00300)也涉及诊断映射单调约束。本文应研究**概念局部性与跨题效应排序**，而不是再包装单调性。DBCD 的反事实预测对齐也不同于这里的“同一证据编辑，对不同探针影响是否不同”。

### 6.3 正负探针如何选

从合法 support 中选学生 i 的一道错题 j，将 −1 改为 +1，得到 \(R_i^+\)。原输入为 \(R_i^-\)。

从该 episode 隐藏的训练 query 中选探针题：

- \(l^+\)：与 j 共享可信锚概念。
- \(l^-\)：与 j 的可信锚概念不相交。
- 不确定、多概念歧义大的题初版跳过。
- 探针不含编辑题，探针答案不进入输入，也不用于选择正负关系。

两类探针应匹配训练难度、曝光量、参考概念数以及冻结教师的基线预测范围。若有可信区分度估计，也应匹配；没有时明确承认残余混杂。先固定候选规则，不让当前模型挑最容易的探针。

冻结参考锚标签决定集合；当前 Q 可以被训练，但不能同时改变“谁是正探针”的答案。

### 6.4 效应与损失

两次前向使用相同题目侧证据 \(\psi_l\)、相同当前 Q、相同网络随机状态，仅改变学生 support。设模型的真实 pre-sigmoid logit 为 \(\ell\)：

\[
d_{ij\to l}=
\ell(\theta(R_i^+),\psi_l,q_l)-
\ell(\theta(R_i^-),\psi_l,q_l).
\]

使用正负探针的二候选对比：

\[
L_{effect}=
\operatorname{softplus}
\left(\frac{d_{ij\to l^-}-d_{ij\to l^+}}{T}\right).
\]

它等价于将 \(d^+/T,d^-/T\) 作为两个候选分数的交叉熵，是相对效应对比。初版 margin=0，减少人为尺度要求；若加正 margin，须作为独立超参记录。

相对排名不保证 \(d^+>0\)：模型可能让相关题下降少、无关题下降多。初版仅声称相对局部性，并报告符号比例。若研究目标明确要求相关预测上升，可另加 \(\operatorname{ReLU}(-d^+)\) 并单独消融，不能偷换结论。

### 6.5 四个必须落到代码的细节

**第一，消除 Dropout 假效应。**当前预测头有 Dropout。若两次前向使用不同随机掩码，差值包含网络噪声。辅助前向可以临时将预测头设为 eval，同时保留 autograd，再恢复训练状态；或共享掩码。主 BCE 仍按原方式训练。

**第二，直接输出 logit。**新增可复用的 predict_response_logit，不用 logit(clamp(p))，后者会因截断制造零梯度。输出 logit 并不消除内部 sigmoid 饱和，仍需监测有效编辑幅度。

**第三，固定题目侧证据。**不得把学生编辑再写回题目列、重新产生另一份 \(\psi_l\)，否则同时改变学生状态和题目难度，无法解释差值。

**第四，限制辅助梯度去向。**初版主 BCE 更新全部参数；效应损失先只把梯度加给 Q 参数。可用 autograd.grad 单独取得 Q 梯度再与主梯度相加，避免预测头独自满足排序。随后比较“辅助更新全部参数”的版本。

可在辅助前向对探针掩码 q_l 停止梯度，只允许 Q 通过学生生成路径更新，用于区分两条作用路径。这不等于只更新编辑源题：所有 support 题的 Q 仍会影响掌握基线和非线性响应。若研究源题局部更新，需进一步将辅助 Q 梯度限制到本批编辑源题对应行，并另列条件。

### 6.6 最值得做的升级：保持净正确数不变

单题错改对会提高净正确数，总表现通道也可能导致效应差异。更有判别力的实验是：

- 概念 k 的一道错题改对；
- 概念 h 的一道正确题改错；
- 观察题数、净正确数均不变；
- 正探针仅关联 k，负探针仅关联 h；
- 额外保留不关联 k、h 的中性探针。

若结果只由整体总分驱动，这一编辑不应制造正确的概念差异；若模型学到了局部结构，应更容易区分三类效应。

这种编辑需要两道具有清楚概念标签且答案相反的题。不存在合格题对时跳过；不能为了凑对篡改更多答案。它比单编辑更能检验机制，但不宜在第一版代码尚未核验时同时加入。

### 6.7 核验、消融与失败条件

先做不训练检查：

1. 零编辑时所有探针效应应接近零。
2. 相同网络状态重复计算效应应一致。
3. 排名损失应有违反样本，且对 Q 梯度非零。
4. query 坐标在学生、题目两侧均为未观察。
5. 不把编辑后的 support 标签作为新的真实 query 标签训练 BCE。

再比较：

| 条件 | 检验什么 |
| --- | --- |
| Weak-Q，无效应损失 | 主基线 |
| Weak-Q＋效应，仅辅助更新 Q | 目标方案 |
| 效应辅助更新全部网络 | 收益是否仅来自预测头 |
| 同锚点的直接 Q 正则 | 复杂效应目标是否优于直接模仿参考标签 |
| 单编辑 vs 净正确数守恒双编辑 | 概念效应与总表现效应的区别 |
| 真锚关系 vs 打乱关系 | 语义是否有用 |
| 冻结 Q＋效应更新其他网络 | 学习 Q 是否必要 |

记录正／负／中性探针的 logit 变化、符号比例、排名正确率、主预测 NLL、logit 尺度和 Q 编辑稳定性。避免仅靠无限放大预测头尺度降低损失。

**支持创新：**净正确数不变时仍能在独立探针上定位概念差异；结构恢复和预测也改善；阻断 Q 的辅助梯度使收益减弱。

**失败条件：**局部排名仅在选定锚题成立，独立探针不成立；随机锚点同样有效；Q 更像参考 Q 但合成真 Q 恢复不变；或全部收益来自头部尺度变化。此时只能描述输入敏感性正则，不能声称诊断结构变真或获得因果解释。

## 七、方向五：非对称 Q 噪声与后验结构视图对比

### 7.1 一句话想法

**参考 Q 可能漏标，也可能多标；显式区分两类错误，得到一组可信 Q 结构，再让同一学生的诊断在这些结构下保持有证据支持的关系。**

前四条主要学习一张点估计 Q；这一条学习“哪些关联确定、哪些关联仍不确定”。增强来自结构不确定性，不翻转学生答案。

这条路线更适合研究 Q 噪声鲁棒性，工程和统计风险最高，应在前面路线有清楚基线后再做。

### 7.2 来源和可能创新在哪里

贝叶斯 Q 推断已存在，SVGCD 已有变分结构视图，UCD 已研究诊断不确定性。因此不能声称首次给 Q 加随机性。

候选贡献是完整链条：**非对称标注过程 → 可解释的边后验近似 → 共享结构视图 → 概念条件 CL → 结构与预测的联合验证。**关键是“视图为什么可信、对比怎样帮助结构”，而不是仅仅采两次随机矩阵。

### 7.3 最小概率模型：先固定错误率

记参考矩阵 \(A=Q^{ref}\)，潜在真实二值边 \(Z_{jk}\)，变分分布：

\[
p(Z)=\prod_{jk}\operatorname{Bern}(Z_{jk};s_k),\quad
q_\phi(Z)=\prod_{jk}\operatorname{Bern}(Z_{jk};\pi_{jk}),
\quad \pi_{jk}=\sigma(a_{jk}).
\]

参考标签噪声通道：

\[
P(A=1\mid Z=0)=f,\qquad
P(A=0\mid Z=1)=n.
\]

f 表示多标／假阳性率，n 表示漏标／假阴性率。第一版固定 \(0<f,n<0.5\)，不要给每条边同时学习错误率和真值，否则极易不可辨识。

- 合成实验可使用已知 f、n。
- 真实数据只能将 f、n 当候选噪声假设，按验证集选择；不是“测出了专家真实错误率”。
- \(\pi\) 可按参考 Q 初始化为 0.95/0.05。
- 先验 s 与初始化不同：首版用固定中性 s=0.5，或明确声明的外部稀疏先验。
- 不把同一个参考 Q 既当独立先验信息，又当独立观测信息重复计入而不说明。

### 7.4 训练目标：把概率含义写正确

G-NCDM 在此提供条件预测：
\[
p_\theta(Y_H\mid R_S,Z),\qquad H\cap S=\varnothing.
\]

固定 support/query 后，负条件变分目标为：

\[
\mathcal J_{VI}=
\mathbb E_q[-\log p_\theta(Y_H\mid R_S,Z)]
+L_A+\operatorname{KL}(q_\phi(Z)\|p(Z)).
\]

其中观测 Q 的解析项：

\[
\begin{aligned}
L_A=-\sum_{jk}\{&
\pi_{jk}[A_{jk}\log(1-n)+(1-A_{jk})\log n]\\
+&(1-\pi_{jk})[A_{jk}\log f+(1-A_{jk})\log(1-f)]\}.
\end{aligned}
\]

KL 为 Bernoulli 的解析 KL。注意：
\[
\operatorname{BCE}(A,f+(1-f-n)\pi)
\ne \mathbb E_q[-\log p(A\mid Z)].
\]
前者是对混合概率取负对数，不是上面 ELBO 中的同一项，不能混写。

为了避免实现时把全局项按 batch 放大，固定总 query 数 \(N_H\)、均匀抽样 batch B 时，可使用：
\[
\widehat{\mathcal J}_{VI}=
\frac1{|B|}\sum_{t\in B}\mathbb E_q\ell_t+
\frac{L_A+KL}{N_H}.
\]
这里 \(L_A\)、KL 都是全矩阵求和。当前 runner 按学生采样，不一定等于均匀采作答；若沿用该采样，应明确选择学生平均还是作答平均，并采用对应权重或采样校正，不能默认上述式子无条件适用。

原始变分目标使用求和量。若主 BCE 使用均值，需相应缩放全局 \(L_A+KL\)；若分别取均值再人为设权重，就明确称加权目标。随机 episode 对应多种条件预测目标的期望，不是自动建立了完整作答矩阵的联合生成模型。

加入 CL 后：
\[
\mathcal J=\mathcal J_{VI}
+\lambda_{cl}\mathbb E_{Z^{(1)},Z^{(2)}}L_{structure}.
\]

应称“对比正则化的变分目标”，不保证得到经过校准的严格贝叶斯后验。

### 7.5 如何采样，避免温度把初始化改掉

第一版采用二值前向、Concrete 反向代理：

\[
u\sim U(0,1),\quad g=\log u-\log(1-u),
\]
\[
z_h=\mathbf1[a+g>0],\quad z_s=\sigma((a+g)/T),
\]
\[
z_{ST}=z_h-\operatorname{sg}(z_s)+z_s.
\]

前向二值概率始终为 \(\sigma(a)=\pi\)，不依赖 T。T 首版固定为 1。这是有偏的直通梯度近似，不是无偏离散梯度。[Concrete 原论文](https://arxiv.org/abs/1611.00712)、[Gumbel-Softmax 原论文](https://arxiv.org/abs/1611.01144)。

不要设置 \(a=T\operatorname{logit}\pi^{init}\) 去强行匹配无噪声 soft 值，那会改变实际二值边概率；也不要把有限温度的 \(z_s\) 样本均值当成 \(\pi\)。

每个视图采一张**全局 Q**，在该视图内所有学生共享；生成和预测两条路径使用同一张结构。不能每个学生拥有一张自己的 Q，否则模型定义已改变。

初版允许随机空行，由似然和先验处理并统计频率。若重采样直到非空，就改变了独立 Bernoulli 分布，需要新的概率模型；不要暗中补边。

### 7.6 结构视图中的正负样本

两张结构 \(Z^{(1)},Z^{(2)}\) 使用相同、保留正误的 support。先采用方向一已经冻结的概念关系池：

- 正对：相同学生同概念跨结构，且该概念有足够参考锚证据；或已有独立证据支持的跨学生正对。
- 负对：同概念、总体表现匹配、独立证据显示明确差异的学生。
- 相似度：概念坐标的固定尺度距离核。
- 关系、证据资格不由当前后验熵决定是否算损失，避免模型把困难样本直接“判成不确定”而逃避。

为隔离“结构视图”的价值，所有后验版本共享同一关系构造，不在这一轮重新搜索负样本策略。

CL 会鼓励结构间稳定，也可能通过让所有 \(\pi\) 过早趋于 0／1 来消除视图差异。记录边熵、两视图差异率、Q 校准和独立预测；低熵不是恢复真结构的证明。

### 7.7 推理方式与公平对照

正式推理建议平均 M 张结构的预测：

\[
\bar p_{ij}=\frac1M\sum_{m=1}^{M}
p_\theta(y_{ij}=1\mid R_{support},Z^{(m)}).
\]

首版 M=16，固定评估采样种子，并检查采样误差。直接用后验均值 \(\pi\) 前向是速度近似，通常不等于平均预测；可以单独报告，不能混为同协议。

二值随机前向不等于固定 0.95/0.05 连续前向，即使期望 Q 相同。因此本方向必须增加以下专属对照：

| 条件 | 排除的混杂 |
| --- | --- |
| 固定连续软 Q | 现有强对照 |
| 冻结 \(\pi\)，同样采样及预测平均 | 随机结构与模型平均本身的收益 |
| 学习后验，对称通道，无 CL | 结构学习基本收益 |
| 学习后验，非对称通道，无 CL | 非对称噪声假设的收益 |
| 非对称通道＋结构 CL | CL 的增量 |
| 上项但阻断 CL→Q | 对比是否真的改善结构分布 |
| 相同边改动率的均匀随机结构视图 | 后验产生视图是否比普通扰动更有效 |

上表“均匀随机结构视图”**只替换 CL 辅助分支**：变分响应项仍从后验采样，解析 \(L_A\)、KL 和正式 Monte Carlo 推理保持不变。用训练期停止梯度的两视图 Hamming 差异率匹配扰动强度，不使用测试指标或真 Q 来调扰动。否则对照会同时改变变分模型，无法单独判断视图选择的贡献。

### 7.8 必须先用已知真 Q 验证

先在合成真 Q 上分别施加漏标、多标、混合噪声。匹配总体污染量时应使用：
\[
r=(1-s)f+sn,
\]
其中 s 是真边密度；不能简单比较 f+n。

报告边 precision／recall、Q-AUPRC、行级完全恢复率、概率校准、不同边类型的不确定性，以及 AUC、ACC、NLL、Brier。若只提高预测平均效果，最多称结构集成或鲁棒预测，不称 Q 修复。

真实参考 Q 再加人工噪声时，恢复目标只是“额外施加的参考扰动”；原参考本身不一定真实。必须与完全合成真 Q 的实验分开。

**支持创新：**在匹配污染量的多种噪声类型中，非对称通道与结构 CL 各有可重复贡献；结构不确定性与真实错误有关；真实预测未因强一致性受损。

**失败条件：**所有收益来自 Monte Carlo 集成；CL 只让后验提前硬化；对噪声率极端敏感；或 Q 与噪声参数互相迁就。此时应回退到确定性方案，不用复杂贝叶斯术语包装无效模块。

## 八、统一实验协议、执行顺序和文件组织

### 8.1 五条路线共用的公平基线

先建立同协议基线，再运行方向实验。以下名称用于新记录，避免继续混用 A1、S1 而看不出 Q 的状态：

| 新记录中的条件名 | Q 设置 | 辅助项 | 用途 |
| --- | --- | --- | --- |
| fixed_binary | 固定参考二值 Q | 无 | 原始 G-NCDM 型对照 |
| fixed_soft | 固定 0.95/0.05 Q | 无 | 排除单纯软化的强对照 |
| learned_no_prior | 同一 0.95/0.05 初始化，可学习 | 无弱 Q 先验、无 CL | 学习本身的贡献 |
| weakq_no_cl | 同初始化可学习 Q＋明确弱先验 | 无 CL | 五条路线的共同主基线 |
| weakq_old_cl | 同上 | 原翻转学生 InfoNCE | 与旧对比目标比较 |
| idea_no_cl | 某方向新增结构／证据机制 | 关闭该方向 CL | 排除新增结构和信息的贡献 |
| idea_with_cl | 与上一行相同 | 开启该方向 CL | 新 CL 的净贡献 |
| idea_detach_q | 同 idea_with_cl | 仅阻断 CL 对 Q 的梯度 | Q—CL 耦合归因 |

0.95/0.05 是根据已有结果选择的统一强起点，不是先验保证的最优值；之后可用 0.55/0.45 做敏感性，但每次冻结／学习比较必须同起点。Q 初始化与 Q 先验强度分别记录。

方向五使用专属随机结构基线，并用标注通道替代原 MSE 弱 Q 项；不要无说明地再叠加同一参考 Q 的 MSE。不能因为均值都为 0.95/0.05，就认为前向映射相同。

若某个方向没有新增可训练结构，idea_no_cl 可以与 weakq_no_cl 是同一份经核验的结果；汇总表明确共享基线，不复制 checkpoint。方向三的固定 Q 残差 CL 可能无任何训练梯度，先核验后跳过冗余完整训练。

一个有用的交互量是：
\[
\Delta_{interaction}=
(M_{\text{learnQ+CL}}-M_{\text{learnQ}})
-(M_{\text{fixedQ+CL}}-M_{\text{fixedQ}}).
\]
它衡量 CL 的效果是否依赖 Q 可学习；不是数学上充分的“协同机制证明”，仍需梯度和结构证据。指标方向要一致，例如 NLL 越低越好。

### 8.2 数据来源与防止循环自证

新设计中容易出现的泄漏不只是把测试标签喂入网络，还包括用隐藏 query 生成教师、近邻、原型或难度特征。

建议统一实现以下规则：

1. 正式 train／valid／test 数据文件不修改，哈希写入 manifest。
2. 每个训练 episode 先抽 query，再从学生行与题目列两侧移除。
3. 总体模型的题目难度按训练学生交叉拟合：例如固定三折，当前学生折使用其他折拟合的难度；同一 episode 优先从同一折抽学生。
4. 学生总体表现只由当前允许的 support 子集估计，不能缓存整名学生全部训练答案得到的 a，再用于每个隐藏 query。
5. 简单 Rasch 可固定题目难度后对每名学生做带正则的一维能力估计；极少作答时退回训练先验均值，同时降低配对资格。
6. 方向一用 B 定关系、A 编码；方向三用 C 定总体表现、A／B 交叉关系。不同方向的数据作用在配置中写清。
7. 题目行为画像与原型只读对应允许的训练证据；原型若按锚题聚合，排除当前题。对全训练矩阵做离线画像时，必须用内部固定的辅助证据／目标划分，不能把当前隐藏目标又填回画像。
8. 验证和测试使用训练证据。其标签只用于计算指定指标；不参与教师、负样本、Q 候选、温度尺度或难度估计。
9. 合成真 Q／真掌握只用于评估与明确声明的 oracle 上界；不得用于普通方法的采样或训练。
10. 参考 Q 与当前 Q 分工明确：冻结参考提供弱语义锚点；当前 Q 提供可微路由。即便参考不随梯度变化，也可能错误，所以仍需独立结构验证。

冻结教师不能自动消除泄漏：一个用目标答案训练或构造的缓存，即使 detach，也可能违背本轮证据协议。detach 只控制梯度，不控制信息来源。

### 8.3 不用一开始跑满五个数据集

推荐分四阶段，顺序固定：

**阶段 0：代数、梯度和样本覆盖检查。**不比较谁的 test AUC 更高。检查无 query 泄漏、空正负集合、标量相似度、梯度路径、同 seed 重现。方向三做等价分解，方向四做零编辑，方向五检查采样频率与目标缩放。

**阶段 1：小规模机制可行性。**合成数据加一个适合该方向的真实数据集，单训练种子 2026。只看训练是否正常、有效样本比例、验证趋势和诊断指标；单种子不作正式收益结论。

**阶段 2：候选筛选与消融。**对通过可行性检查的路线，使用 2026、2027、2028 三个配对训练种子；在验证集选择候选。先做最关键的一至两个对照，再扩展，不一次排列所有模块组合。

**阶段 3：确认与稳健性。**锁定最终机制与选参程序，再扩展五套真实数据和一个未用于方案形成的划分／数据。必要时增加 2029、2030 两个种子。固定划分下五个训练种子仍不是五个独立数据样本；不能只靠种子数证明泛化。

现有测试结果已参与方案形成，后续在相同测试集上的结果应视为探索延续。新的未使用划分属于进一步确认，但来自同一数据池仍不等于外部验证；最终论文应诚实说明。

### 8.4 推荐实施顺序

| 顺序 | 实验 ID | 首个科学问题 | 第一轮只做的改变 | 进入下一轮的条件 |
| --- | --- | --- | --- | --- |
| 0 | wqcl_control_init_v1 | 软化、学习、弱先验分别贡献什么 | 统一初始化与公平对照 | 基线可复现、归因清楚 |
| 1 | wqcl_d1_concept_relation_v1 | 独立概念关系能否替代身份对比 | 换配对与概念损失，主干不变 | 覆盖率足够、关系能复现 |
| 2 | wqcl_d2_item_structure_v1 | 题目证据能否选择有效 Q 编辑 | 预算版本及其同结构 CL | Q 不失控、独立结构指标改善 |
| 3 | wqcl_d3_residual_contrast_v1 | 去掉对比中的总表现后是否更有效 | 保持主预测不变，只换 CL 表示 | 等价核验通过，优于同配对 θ 对比 |
| 4 | wqcl_d4_local_effect_v1 | 证据编辑能否定位概念作用 | Q 辅助效应排序 | 非零梯度、独立探针有效 |
| 5 | wqcl_d5_posterior_structure_v1 | 噪声通道与结构视图是否各有贡献 | 先非对称后验，再单独加 CL | 合成结构／校准先成立 |

方向一和方向二可按样本覆盖情况交换顺序。若局部关系覆盖很低，先做题目端方向二，比放宽负样本阈值硬凑配对更合理。

**最推荐的最终组合候选：方向二的受限 Q 学习＋方向一或三的概念关系 CL。**理由是前者约束“结构能改多少、改在哪里”，后者约束“改出来的结构能否支持可重复的概念差异”。但必须各自先有效，再做组合交互实验；不能预先保证两者叠加更好。

### 8.5 参数怎么选，避免无限搜索

以下系数建议主要用于方向一至四；方向五按照其变分项的缩放单独配置。先沿用当前可复现训练器的公共参数作为起点：训练种子配对、相同数据划分、相同 batch／优化器设置，\(\alpha=0.8\) 暂不同时搜索。对于以前在训练上限附近仍改善的情况，基线和方法都给予相同的更充分预算，不能让基线少训。

建议每个新损失都按“有效监督单位”取平均，再采用小网格：

| 参数 | 起步候选／建议 | 说明 |
| --- | --- | --- |
| \(\lambda_{cl}\) | 0、0.001、0.01、0.1 | 0 是必需对照；不是保证最优的候选集 |
| \(\lambda_q\) | 0、0.001、0.01、0.1 | 先在无新 CL 的统一基线上选；随后限定联合小网格 |
| 距离／余弦温度 | 首版 0.2；必要时 0.1、0.5 | 标量距离已标准化才有可比尺度 |
| 关系证据数 | 每份每概念至少 3 条作为保守起点 | 3 条仍不保证可靠；同时看差异区间与覆盖率 |
| 每个 anchor 的正／负数量 | 最多各 4 个，batch 内采样 | 先不用 queue，避免跨版本伪标签陈旧 |
| Q 编辑预算 | 每题约 1、2 的软预算量级 | 不等于真实增删边数 |
| 方向四效应 margin | 首版 0 | 不先靠大 margin 放大 logit |
| 方向五噪声率 | 合成用已知值；真实用少量预注册假设 | 选择的是假设，不是测得真实错误率 |

为减少损失尺度误导，先记录：
\[
r_Q=
\frac{\|\lambda_{cl}\nabla_Q L_{CL}\|}
{\|\nabla_Q L_{pred}\|+\epsilon}.
\]
若辅助梯度远大于主梯度、同时验证恶化，应减小系数；若几乎为零，先查计算图和采样覆盖，不是机械加到 100。该比值是诊断工具，不存在保证收益的通用目标值。

所有候选、试验顺序和选择规则提前写入配置。首批固定规则：最大平均验证 AUC；数值等同到预定精度时比较验证 NLL，再优先简单模型。测试 AUC／ACC 不参与系数、checkpoint、阈值、种子选择。

同一方向与基线给予可比的调参预算。不能挑最差 baseline、挑最好 seed；主表使用同种子配对结果和完整均值。

### 8.6 记录哪些指标，怎样判断“有效收益”

**预测层：**AUC、ACC、NLL、Brier，至少同时报告 AUC 和 ACC。ACC 默认使用固定 0.5 阈值；若选择其他阈值，只能用验证集并另列，不能在测试上挑最佳阈值掩盖下降。

**结构层：**Q 的平均值、硬密度、行和、增边／删边数、跨种子一致性。真 Q 已知时增加 precision、recall、AUPRC、行级完全恢复；真实参考 Q 只能报告参考一致性。

**诊断层：**合成真掌握误差和排序；独立锚题／支持证据的概念分辨；方向四的编辑局部性；不同证据量学生的表现。评估不能重复使用训练配对的同一批代理标签来证明自身正确。

**优化层：**有效正负覆盖率、真实视图差异、Q 梯度范数与方向、饱和比例、训练耗时和必要显存。effective rank 仅作描述，不作为选模指标。

如何下结论：

- 如果 AUC 上升但 ACC／NLL 下降，写清楚权衡，不写全面提升。
- 如果全部提升只有约 \(10^{-4}\)，必须结合配对方差、重复划分和实际用途解释，不能仅因正号就宣布有效。
- 可在搜索前设项目的实际增益门槛，例如平均验证 AUC 至少 +0.001 且无明显校准恶化；这只是资源分配标准，不是通用统计显著性阈值。
- 三种子报告均值、标准差、逐种子差值和正向种子数。需要置信区间时，按学生聚类重采样，避免将同一学生多条作答当成完全独立。
- 不同划分与种子涉及不同变异来源，不能把所有样本简单混起来得到虚假的窄区间。
- 五个方向、多组参数都试过，要完整记录探索范围；最终确认方案在未参与选择的评估上检验。

一个方向可以有**预测贡献**、**结构贡献**或**诊断贡献**；支持哪一项就写哪一项。只有在控制其他新增信息后 CL 仍有增量，才把该增量归给 CL。

### 8.7 合成验证应怎样设计才有说服力

当前已有合成数据可以做流程检查，但不应只用一种与模型同构的生成过程证明普适性。

建议至少两类生成机制：

1. 多维加性逻辑模型：题目概率由相关概念掌握、题目难度共同决定。
2. 具有合取／交互特点的诊断生成过程：用于检查方法面对非加性概念要求时是否仍有效。

设置学生总体表现相近但概念偏科相反的群体；控制概念相关性、每人作答量、题目概念数。分别产生缺失交互和 Q 的 missing／redundant／mixed 噪声，记录数据 seed 与训练 seed。

不要只生成彼此独立的概念；也不要把模型自己的当前 Q 当作合成“真 Q”。真 Q、真掌握只在评估函数可见。真实数据不具备的 oracle 信息，只能放入明确标识的上界对照。

若方向只在与其假设完全一致的模拟上有效，在另一种生成机制失效，这仍是有价值的边界，应保留负结果。

### 8.10 可以怎样形成论文贡献，而不夸大

若最终验证支持，贡献可以组织为：

1. **问题层：**分析生成式诊断中 Q 结构、总体表现和学生身份对比之间的冲突，用控制实验说明原始 CL 为什么缺乏稳定收益。
2. **方法层：**提出其中一条经过验证的 Q—CL 联动机制，例如有限 Q 编辑下的题目证据对比，或独立证据支持的概念关系对比。
3. **证据层：**在真实预测、已知结构恢复、概念诊断、噪声／稀疏条件、梯度路径和公平消融上形成一致证据。

如果没有结构恢复证据，就写“弱结构引导的预测模型”；如果新 CL 不优于相同信息的普通监督，就承认贡献来自证据建模；如果最终只有一个方向成功，也足以围绕这个方向做完整研究。

**本方案最核心的判断是：让对比学习回答一个可验证的诊断问题，而不是让它仅仅把学生表示推开。**五条路线分别提供了五种可检验的问题定义；哪一种适合当前数据，需要按照上述对照来决定。
