### 0.2 组合策略：为什么新增五个偏向 Q 结构与评估侧

已有证据的不对称性：

- **CL 侧**：翻转 InfoNCE、遮蔽替换、投影头（两种）、预测一致性、证据加权一致性——六种机制在五套数据上全部没有稳定收益（test_sim_con 正式记录）。继续在"换一种作答增强"上投入，边际期望低。
- **Q 侧**：Weak-Q (A1) 对固定 Q (A0) 的预测收益在五套真实数据一致为正（AUC +0.0056 ~ +0.0184）；固定 0.95/0.05 软 Q 是收益最清楚的强对照（ΔAUC 最高 +0.0088）。

因此新增五个方向的组合逻辑是：

- **方向 6/10 是"评估基础设施型"**——不需要新训练就能产出结论和论文素材（可靠性章节、冷启动章节），风险最低、启动最快；
- **方向 7/9 是"弱监督与聚合结构型"**——直接强化已经证明有效的 Q 路径，与 D2 形成互补（D2 改 Q 的 0/1 结构，7 改先验置信度，9 改行内归因）；
- **方向 8 是"鲁棒正则型"**——把"固定软 Q 为什么有效"这个已有发现升级为一个可泛化的机制，同时顺带完成原计划中悬置的"软 Q 收益来自哪条路径"的归因消融。

与原五方向合并后的选项池覆盖了：CL 样本关系（D1）、Q 结构编辑（D2）、CL 输入表示（D3）、编辑效应（D4）、结构不确定性（D5）、可辨识性（6）、先验置信度（7）、鲁棒平滑（8）、行内归因（9）、证据效率（10）。**毕业工作的厚度应来自其中一条做深 + 其余做消融/讨论，而不是十个全做。**

## 一、既有方向 1：跨证据的概念关系对比（D1）

> 完整设计：原文档第三节。实验 ID：`wqcl_d1_concept_relation_v1`。

**一句话**：用一部分答题证据（B）判断"两个学生在概念 k 上是否相似"，用另一部分证据（A）产生诊断表示，再要求这个关系能复现；正负关系由"同概念 + 总体表现相近 + 残差差异区间足够小/大"三类条件联合判定，总体表现相近既不是正例条件也不是负例条件。

**想法来源**：test_sim_con 已证实原始 InfoNCE 的三个缺陷——①目标错位：让所有不同学生的表示分开，等于学"识别学生身份"，而认知诊断需要相同知识状态有相近解释；②整向量相似掩盖概念偏科：甲乙总成绩接近、但甲"函数"强"几何"弱、乙相反时，一个余弦值无法表达这种相反关系；③假负样本：batch 内其他学生常是认知状态相近的假负例。D1 把对比的单位从"学生"降到"**学生×概念**"，把配对依据从"同一学生"换成"独立证据支持的概念关系"。

**为什么算创新**：

| 最近邻 | 覆盖 | 差异 |
| --- | --- | --- |
| SCD (AAAI 2023) | 图视图自监督 | 视图来自图增强，配对=同一学生 |
| DCD (NeurIPS 2023) | 弱标签概念对齐 | 需要有限人工标签；D1 只用作答+参考 Q |
| PLCD (EMNLP 2026 Findings) | 过程级对比 | 依赖文本；D1 无文本 |
| [假负样本通用研究 (NeurIPS 2020)](https://papers.neurips.cc/paper_files/paper/2020/hash/63c3ddcc7b23daa1e42dc41f9a44a873-Abstract.html) | 假负问题本身 | D1 的解法是认知诊断特有的"同概念+表现匹配+可重复残差差异" |

可辩护差异："**生成式诊断中，以独立作答证据建立总体表现条件下的概念关系，作用于由可学习 Q 生成的诊断坐标**"。实施前需再检索一次最近邻。

**如何实现**（最小版，两份证据，不做三视图）：

1. episode 内先抽 query H（双侧移除，照旧），再把 support 随机分 A/B：A 产生掌握表示 `θ_i^A`；B 只建立正负关系（关系掩码停止梯度）；交换 A/B 复算一次；主 BCE 仍用 A∪B 预测 H。
2. 概念锚题集 `E_k` 来自**冻结**参考 Q（单概念题优先，多概念题降权 w_j=1/|Q_j|）；锚只是"相对可信参考"，不是真值。
3. 去混杂教师（train 内交叉拟合，difficulty 按三折）：`p̂^g_ij = σ(a_i − b_j)`；计算 A←B 关系时 `a_i` 只用 B 中不属于 k 锚题的记录估计（记 `a_i^{(−k),B}`），防止残差被评分方程压零；B 几乎只有概念 k 时跳过。
4. B 上的概念残差代理与配对判定：

```text
t^B_ik = Σ_{j∈B_i∩E_k} w_j·(y_ij − p̂^g_ij) / (ε + Σ w_j)      # w_j=1 首版
区间 I^B_ik：训练题重采样 bootstrap；样本不足→跳过（不硬造）
正例 u：(t^B_ik − t^B_uk) 的区间整体 ⊆ [−δ_p, δ_p] 且总体表现相近(|a_i−a_u|≤δ_a)、证据量相近
负例 u：区间整体在 +δ_n 右侧或 −δ_n 左侧（δ_n > δ_p）
其余：未知，不参与本项损失（绝不把中间组归为负例）
```

5. 相似度与损失（直接用可学习 Q 生成的概念坐标，不新增投影头）：

```text
x^A_ik = θ^A_ik；  s_k(i,u) = −(x^A_ik − x^A_uk)² / (scale_k² + ε)
scale_k 在无 CL 阶段估计并冻结（变量名 scale_k，避免与相似度函数重名）；首版可统一为 1+温度控制
L_rel^{A←B} = −1/|V| · Σ_{(i,k)∈V} 1/|P^B_ik| · Σ_{u∈P^B_ik}
              log[ exp(s_k(i,u)/τ) / Σ_{v∈P^B_ik∪N^B_ik} exp(s_k(i,v)/τ) ]
V 只含同时有正负例的学生—概念；排除自身；无有效项返回可导零并记录覆盖率
L = L_pred + λ_q·L_weakQ + (λ_cl/2)·(L_rel^{A←B} + L_rel^{B←A})
```

Q 的梯度经 θ^A/θ^B 的显式聚合进入；**采样标签不从当前 Q 接收梯度**。初版不改 α。

**验证设计**：

| 消融 | 检验什么 |
| --- | --- |
| 同结构 Weak-Q 无 CL | 新 CL 的净贡献 |
| 原学生 InfoNCE（同预算） | 是否真正解决身份错位 |
| 概念关系但不匹配总体表现 | 是否只是学了总分分组 |
| 同份证据定标签并编码（vs A/B 独立） | 自我证明/过拟合配对规则 |
| 固定 Q vs 学习 Q；CL 路径 Q.detach | 收益是否需要 CL 直接改 Q |
| 同样伪标签的普通回归/成对排序 | 收益来自对比形式还是关系监督本身 |
| 打乱概念关系 | 语义是否真有用 |

- 阶段 0 先只输出覆盖率（正/负/有效项比例）不训练；合成数据验证"真概念差异能被 t 区间捕捉"，再上 Eedi/Junyi 高证据学生。**Math1/Math2 题少，A/B 拆分后单概念证据可能不足，不能因矩阵稠密就假定适合**；ASSIST 单独报低证据学生覆盖率。
- 支持创新的证据：验证预测不劣 + 概念关系跨证据复现改善 + 合成出现结构/诊断收益 + CL→Q 阻断后收益减弱。
- **停止条件**：有效配对覆盖率极低；收益只在头部学生；普通关系回归已拿走全部收益；概念分组指标涨但预测与校准受损——出现任一条即缩小结论。

## 二、既有方向 2：有限 Q 编辑与题目作答—结构对比（D2）

> 完整设计：原文档第四节。实验 ID：`wqcl_d2_item_structure_v1`。

**一句话**：让每道题的作答证据画像与它的概念结构表示互相核对（InfoNCE），用"每题软编辑预算"惩罚无差别的大规模 Q 修改，使 CL 直接选择"哪些 Q 关联值得修改"——CL 的对象从学生换成题目，对 Q 的梯度路径最直接。

**想法来源**：A1 学到的 Q 稠密化（hard density 0.33–0.64 vs 参考 0.01–0.30）且参考 Q-F1 低（0.056–0.445）——Q 在无约束地"搬运总表现"而不是恢复题目真正需要的概念。例如某题原标"分式"，独立学生群体的表现却更像"方程"题：在保留原结构约束的前提下，对比应支持增加方程关联；而所有题都因正确率相近而相似时，应被难度控制与假负样本检查拦住。

**为什么算创新**：DCD（题目标签分布）、正则化 Q 校验（BJMSP/JEBS 2025）、2026 Q 原型对比预印本都是近邻；可辩护差异是"**对现有弱 Q 的有限编辑 + 独立作答证据与结构表示的匹配 + 区分行为难度相似与概念关联相似**"这一整套可检验机制，而不是单独一个正则项。

**如何实现**（首版直接约束实际编辑量，不加门控）：

1. 统一初始化与编辑量：

```text
P^0 = 0.05 + 0.90·Q^0，  Q = σ(S)，  S^init = logit(P^0)
E_j = Σ_k |Q_jk − P^0_jk| / 0.90                        # 每题软编辑量（0.05→0.95 完整反转=1 单位）
L_budget = (1/J)·Σ_j [max(0, E_j − B_j)]²                # B 是软预算目标，不保证硬上界
L_edit   = (1/JK)·Σ_jk |Q_jk − P^0_jk|                   # 额外 L1，首版系数设 0（防三重锁死）
```

另须报告：超预算比例、超额量、**跨越 0.5 的真实增删边数**（软预算 ≠ 实际改了几条边）。预算 B 从每题 1、2 起步，按验证集选。**两个禁忌**：① 不要先加门控 `Q=(1−G)P^0+GV`——V 初始化为 P0 时 G 的初始梯度为零，大 K 下会明显拖慢 Q 学习；② 有界 logit 残差 `Q=σ(logit P^0 + δ·tanhΔ)` 在 δ≤log19 时**无法实现真正的 0↔1 反转**，只能称关联重加权。

2. 题目作答视图（避免只学难度）：每题两组**不重叠训练学生** U/V（每轮重划），与预测 query 不重叠；构造残差画像 `ρ_ij = m_ij(y_ij − p̂^g_ij)`（**观察掩码必须输入**，缺失不能当零残差），拼 `[ρ^U, m^U]` 过小 MLP 出 K 维 `z_j^{R,U} = norm(r_φ(·))`。r 是新建的题目相关性头——**不直接复用 ψ_j**（ψ 本来用于难度建模）。
3. 结构视图与正负样本：概念原型**固定为标准基** `c_k=e_k`，`z_j^Q = norm(q_j)`——语义坐标固定，不给 Q 与可学习原型一起旋转成题目 ID 编码的机会。正对 = 同题的作答视图×结构视图（U、V 各一）；负例 = 难度/作答量相近且**冻结锚标签不相交**的题；参考标签相同或高度重合的题移出负集（初版不作多正例）；未标注/冲突的题不算负例；相似度用归一化余弦。

```text
L_RQ = −1/(2|J|) · Σ_{j∈J} Σ_{v∈{U,V}} log[ exp(cos(z_j^{R,v}, z_j^Q)/τ)
        / ( exp(cos(z_j^{R,v}, z_j^Q)/τ) + Σ_{ℓ∈N_j} exp(cos(z_j^{R,v}, z_ℓ^Q)/τ) ) ]
L = L_pred + λ_q·L_weakQ + λ_e·L_edit + λ_b·L_budget + λ_cl·L_RQ
```

主任务与 CL 用同一个 Q，梯度路径 `L_RQ → z^Q → Q → S` 明确存在。

4. 防止作答头与 Q 互相迁就（三约束）：固定概念坐标+预算+弱锚定；作答头可选"训练锚题参考概念的多标签预训练"（配置项，所有同结构对照必须得到完全相同的预训练；若预训练贡献明显，须单独对照"同预训练+普通多标签 BCE"）；固定一批未参与相关性头拟合的训练内学生做结构—行为一致性核验（不经过 r；注意固定 N 维 MLP 中这批学生的输入列权重未被训练，不能宣称新学生泛化）。

**验证设计**（先在 Eedi/Junyi 做——Math1 仅 20 题、Math2 仅 16 题，不适合题目批量 InfoNCE）：

| 步骤 | 条件 | 检验 |
| --- | --- | --- |
| 1 | 只加编辑参数化+预算，CL=0 | 预测与 Q 的变化是否可控 |
| 2 | 冻结 Q，只训练相关性头 | 行为画像里到底有没有概念信息 |
| 3 | 预算 Q + 跨视图 CL | 本方向主体 |
| 4 | 阻断 CL→Q（保留主任务梯度） | CL 是否真的在改结构 |
| 5 | 同信息、同相关性头改多标签 BCE/结构重建 | CL 形式是否必要 |
| 6 | 去预算 / 打乱配对 / 取消难度匹配 / 原始画像替代残差 | 各单一消融 |

核心指标：AUC/ACC/NLL/Brier 之外，必须报 Q 增删边数、总质量与硬密度、**跨种子编辑一致率**、不同噪声类型的边恢复（合成）、独立学生上的题目概念识别；硬阈值预先固定或只用验证/合成选。支持创新的证据：CL 优于同信息 BCE；预算防住了无差别稠密化；Q 改善可在独立作答与合成真 Q 上复现；阻断 CL→Q 后结构收益消失。**停止条件**：只有作答头准确率涨而 Q/预测无改善；Q 只编码题目身份；随机配对同样有效；低维语义与难度无法区分——此时最多称"题目表示正则化"。

## 三、既有方向 3：保留总表现的概念残差对比（D3）

> 完整设计：原文档第五节。实验 ID：`wqcl_d3_residual_contrast_v1`。

**一句话**：预测仍用全部信息（精确分解 `G+U = RQ/√K`，关 CL 时与原模型逐数值一致），但 CL 只比较"扣除总体表现预期后的概念残差"，避免对比目标退化为总分排序——D1 改"谁和谁比"，D3 改"比什么"。

**想法来源**：固定软 Q 有精确代数分解——

```text
Q_ε = (1−2ε)·Q^0 + ε·1_J·1_K^T
RQ_ε = (1−2ε)·RQ^0 + ε·(R·1_J)·1_K^T        # 第二项 = 净正确数复制到每个概念
θ ⊙ q_j^ε = (1−2ε)·(θ⊙q_j^0) + ε·θ           # 预测端的背景通道
```

0.95/0.05 对应概念项系数 0.9、共同项 0.05；0.55/0.45 对应 0.1 和 0.45。共同项受正确率、作答数、难度与选题分布影响，不是真实总能力——这是软 Q 收益的可疑通道（严格代数事实；是否为全部实测收益的原因须由路径消融回答）。注意：该等式针对当前**未按题量归一化**的聚合，改加权平均需重新推导。

**为什么算创新**：概念解耦已有（DCD、[Coral, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/013f9cd52b38e3e53475605d2b8e7c23-Paper-Conference.pdf)）；可辩护差异是"**针对 G-NCDM 软 Q 的共同信息通道，在保持原预测映射数值等价的条件下重定义 CL 输入，使其提供概念特异的 Q 梯度而不消除预测有用的总体表现**"——等价性核验让它极易证伪，比"加一个解耦模块"具体得多。

**如何实现**：

1. 精确分解（先核验等价，再训练）：冻结梯度的训练内 Rasch 教师 `p̂^g_ij=σ(a_i−b_j)`，定义

```text
U_ik = (2/√K)·Σ_j m_ij·q_jk·(y_ij − p̂^g_ij)      # 剩余证据项
G_ik = (1/√K)·Σ_j m_ij·q_jk·(2p̂^g_ij − 1)         # 教师 解释的期望项
严格有 G + U = RQ/√K
主预测：θ_i = (1−α)·f_φ(R_i) + α·σ(G_i + U_i)      # 关 CL 时与原模型数值一致
```

阶段 0 的第一件事：对全体学生核验 `G+U` 与原 `RQ/√K` 逐数值一致。G/U 依赖概念 k 的题目组成，不是被唯一识别的心理潜变量，解释时要克制。

2. CL 输入与配对：support 分 **C:A:B = 20%:40%:40%**（起点，须看有效概念覆盖率；不能为凑比例复制作答）：C 只估该学生的 `a_i`，题目难度来自其他学生折；A 算归一化残差均值 `z^A_ik = Σ_{j∈A_i} q_jk(y_ij−p̂^g_ij) / (κ + Σ_{j∈A_i} q_jk)`（κ 固定小常数并报告）；B 建同概念正负关系；**交换 A/B**；两个方向共享 C 的 a_i；主 BCE 仍用 C∪A∪B。复用 D1 已核验的关系损失，**仅替换输入量 θ→z**，配对规则/温度/预算完全相同；θ 版对照必须在 D3 内部重跑（不能跨实验相减归因）。不要把标量送进余弦 InfoNCE（归一化后只剩正负号）。
3. 梯度与防捷径：教师/尺度/配对全部停止梯度时，可训练参数主要是 Q（`L_res → z^A → Q`），应如实称为"**残差驱动的 Q 正则**"，不声称编码器获得新监督。Q 可能通过整体压权重、扩大无关覆盖来改变残差尺度——保留弱先验并监测 Q 总质量。证据量筛选不能只用 `n_eff=(Σq)²/(Σq²+ε)`（一批极小且相等的 q 也会得大 n_eff），还要检查锚题数与总权重下限。
4. 组合说明：方向四的"证据自适应 α"与本方向的分解正交，但**不要首版同时打包**；若后续确需把 a 送入预测头（如 `ℓ_ij = ℓ^GNCDM_ij + β_j·a_i`），是额外架构改动，必须单列"加 a 通道但无 CL"对照，不得再称等价分解。

**验证设计**：

| 对照 | 作用 |
| --- | --- |
| 原模型 vs G+U 分解、CL=0 | 数值等价性（排除重写主干干扰） |
| 同一关系损失作用于 θ vs 残差 z | 表示选择的净贡献 |
| 原始净作答聚合 vs 难度校正残差（同一平滑/分母） | 残差化的净贡献 |
| 能力匹配 vs 不匹配 | 是否仍只在区分总表现 |
| 残差 CL vs 同关系普通排序 | CL 形式是否必要 |
| Q 只用于生成 / 只用于预测 / 两处均学习 | 软 Q 背景通道在哪条路径产生收益 |

优先数据：Eedi/Junyi 证据充分样本；**合成数据设置"总表现接近、概念偏科相反"的学生组**是验证核心假设最直接的场景。支持创新：同配对下残差对比更能识别概念偏科并改善 Q/独立预测；梯度不是把每题所有 Q 边一起抬高。失败情形：Rasch 代理过糙（残差≈模型误设）；残差不跨证据复现；CL 只学到曝光偏差；须丢弃大多数学生才有效。残差趋零不能解释为掌握提高。

## 四、既有方向 4：概念局部的作答编辑效应对比（D4）

> 完整设计：原文档第六节。实验 ID：`wqcl_d4_local_effect_v1`。

**一句话**：不要求编辑作答前后掌握不变，而要求一次证据变化（错题改对）对"共享概念探针"的影响大于对"无关概念探针"的影响；比较的是**模型对证据变化的响应方式**，不是学生向量本身。

**想法来源**：①架构事实：学生编码器非负有效权重 + Q 非负 ⇒ `R⁺ ≥ R⁻ ⇒ θ(R⁺) ≥ θ(R⁻)`，所以 `ReLU(θ(R⁻)−θ(R⁺))` 恒为零——CMCD 式单调约束在此架构中不可用；显式分支的单题变化又与该题 Q 行成比例，用当前 Q 当目标会循环自证。②"翻转作答+拉近表示"已失败——把问题改成"编辑的**效应**是否有合理的概念定位"（如把一条"分数计算"错题改对，模型对其他分数题的预测变化应大于对无关几何题的变化）。注意这只是**作答证据编辑效应**，不产生新真实标签、不构成教学干预的因果声明。

**为什么算创新**：CMCD（翻转+单调）、ID-CDM（[WWW 2024](https://arxiv.org/html/2309.00300)，诊断映射单调约束）、DBCD（反事实预测对齐）都是近邻；可辩护差异是"**同一证据编辑，对不同探针影响是否不同**"这一可证伪的局部性定义，研究的是概念局部性与跨题效应排序，不是再包装单调性。

**如何实现**：

1. 探针选择（规则先固定，不让模型挑容易的）：从合法 support 选学生 i 的错题 j，−1→+1 得 `R_i⁺`（原输入 `R_i⁻`）；从该 episode 隐藏的训练 query 中选探针：`l⁺` 与 j 共享**冻结参考锚**概念，`l⁻` 与 j 的锚概念不相交；不确定/多概念歧义大的题跳过；探针不含编辑题、其答案不进输入也不用于选正负关系；两类探针须匹配训练难度、曝光量、参考概念数与冻结教师基线预测范围（有可信区分度估计也匹配；没有则明确承认残余混杂）。
2. 效应与损失（两次前向：相同 ψ_l、相同当前 Q、相同网络随机状态，仅改学生 support）：

```text
d_{ij→l} = ℓ(θ(R_i⁺), ψ_l, q_l) − ℓ(θ(R_i⁻), ψ_l, q_l)      # ℓ = pre-sigmoid logit
L_effect = softplus( (d_{ij→l⁻} − d_{ij→l⁺}) / T )            # 二候选对比，等价于以 d±/T
                                                              # 为分数的交叉熵；margin 首版=0
```

相对排名不保证 `d⁺>0`（模型可能让相关题降得少、无关题降得多）——初版只声称相对局部性并**报告符号比例**；若要求相关预测上升，另加 `ReLU(−d⁺)` 并单独消融，不偷换结论。
3. 四个必须落到代码的细节：① **消除 Dropout 假效应**——辅助前向把预测头临时设 eval（保留 autograd）再恢复，或共享掩码；主 BCE 照旧；② **直接输出 logit**——新增可复用 `predict_response_logit`，禁止 `logit(clamp(p))`（截断制造零梯度）；输出 logit 不消除内部 sigmoid 饱和，仍监测有效编辑幅度；③ **固定题目侧证据**——不得把编辑写回题目列重算 ψ_l，否则学生状态与题目难度同时改变，差值不可解释；④ **限制辅助梯度去向**——初版效应损失只把梯度加给 Q（`autograd.grad` 单取 Q 梯度再与主梯度相加，防预测头独自满足排序），"辅助更新全部参数"作为后续对照。可另对探针掩码 q_l 停梯度以区分两条 Q 作用路径。
4. 升级实验（最有判别力，第二版再加）：**净正确数守恒双编辑**——概念 k 的错题改对 + 概念 h 的对题改错，观察题数与净正确数均不变；正探针仅关联 k、负探针仅关联 h、另留中性探针。若效应只由总分驱动，此编辑不应制造正确概念差异；需要两道概念清楚且答案相反的题，凑不齐就跳过。

**验证设计**：先做不训练检查——零编辑时所有探针效应≈0；同网络状态重复计算一致；排名损失存在违反样本且对 Q 梯度非零；query 坐标在学生、题目两侧均未观察；不把编辑后 support 标签当真实 query 标签训练 BCE。

| 条件 | 检验什么 |
| --- | --- |
| Weak-Q 无效应损失 | 主基线 |
| Weak-Q+效应，仅辅助更新 Q | 目标方案 |
| 效应辅助更新全部网络 | 收益是否只来自预测头 |
| 同锚点的直接 Q 正则 | 复杂效应目标是否优于直接模仿参考标签 |
| 单编辑 vs 净正确数守恒双编辑 | 概念效应与总表现效应的区别 |
| 真锚关系 vs 打乱关系 | 语义是否有用 |
| 冻结 Q+效应更新其他网络 | 学习 Q 是否必要 |

记录：正/负/中性探针的 logit 变化、符号比例、排名正确率、主预测 NLL、logit 尺度、Q 编辑稳定性（防止靠放大预测头尺度降损）。**支持创新**：净正确数不变时仍能在独立探针上定位概念差异；结构恢复与预测同时改善；阻断 Q 的辅助梯度使收益减弱。**失败条件**：局部排名只在选定锚题成立、独立探针不成立；随机锚点同样有效；Q 更像参考 Q 但合成真 Q 恢复不变；收益全部来自头部尺度变化——此时只能称"输入敏感性正则"。

## 五、既有方向 5：非对称 Q 噪声与后验结构视图对比（D5）

> 完整设计：原文档第七节。实验 ID：`wqcl_d5_posterior_structure_v1`。

**一句话**：用非对称噪声通道 `P(A=1|Z=0)=f（多标/假阳性）、P(A=0|Z=1)=n（漏标/假阴性）` 对参考 Q 建边级 Bernoulli 变分后验 `π_jk=σ(a_jk)`，每个视图采一张**全局**二值 Q，同一学生在不同可信结构下的诊断保持有证据支持的概念关系——前四个方向学点估计 Q，这条学"哪些关联确定、哪些仍不确定"。增强来自结构不确定性，不翻转学生作答。

**想法来源**：漏标与多标的后果不同——漏标压制真实证据、多标搬运总表现——均匀 MSE 先验无法区分这两类错误；而工程与统计风险最高，应在前面路线有清楚基线后再做。

**为什么算创新**：贝叶斯 Q 推断（BJMSP 2025）、变分结构视图（SVGCD）、诊断不确定性（UCD）都是近邻；可辩护差异是完整链条"**非对称标注过程 → 可解释的边后验近似 → 共享结构视图 → 概念条件 CL → 结构与预测联合验证**"——关键是"视图为什么可信、对比怎样帮助结构"，而不是仅仅采两次随机矩阵。

**如何实现**：

1. 最小概率模型（首版固定错误率，**不要**同时学每条边的错误率和真值——不可辨识）：

```text
p(Z) = Π_jk Bern(Z_jk; s_k)，  q_φ(Z) = Π_jk Bern(Z_jk; π_jk)，  π_jk = σ(a_jk)
P(A=1|Z=0) = f，  P(A=0|Z=1) = n          # 首版固定 0<f,n<0.5
合成实验用已知 f,n；真实数据把 f,n 当候选噪声假设按验证集选（不是测出专家真实错误率）
π 按参考 Q 初始化 0.95/0.05；先验 s 与初始化不同：首版固定中性 s=0.5
不把同一参考 Q 既当独立先验又当独立观测重复计入而不说明
```

2. 训练目标（把概率含义写正确）：support/query 固定后的负条件变分目标

```text
J_VI = E_q[−log p_θ(Y_H | R_S, Z)] + L_A + KL(q_φ(Z) || p(Z))
L_A = −Σ_jk { π_jk[A_jk·log(1−n) + (1−A_jk)·log n]
            + (1−π_jk)[A_jk·log f + (1−A_jk)·log(1−f)] }        # 解析项；KL 为 Bernoulli 解析式
⚠️ BCE(A, f+(1−f−n)π) ≠ E_q[−log p(A|Z)] —— 前者是对混合概率取负对数，不能混写
batch 缩放：固定总 query 数 N_H、均匀采 batch 时可用 Ĵ = mean_B E_q ℓ_t + (L_A+KL)/N_H；
当前 runner 按学生采样 ≠ 均匀采作答，须显式选择学生平均/作答平均并配权重校正
```

3. 采样（避免温度把初始化改掉）：二值前向 + Concrete 反向的直通梯度

```text
u~U(0,1)，g = log u − log(1−u)；z_h = 1[a+g>0]；z_s = σ((a+g)/T)；z_ST = z_h − sg(z_s) + z_s
前向二值概率始终 = σ(a) = π，不依赖 T；T 首版固定 1（有偏直通近似，不是无偏离散梯度）
不要设 a = T·logit(π^init) 去匹配无噪声 soft 值；不要把有限温度的 z_s 样本均值当 π
每个视图采一张全局 Q（视图内所有学生共享，生成与预测两条路径同结构）；
初版允许随机空行并统计频率——不要重采样补边（那会改变分布）
```

4. 结构视图中的正负样本：两张结构 Z⁽¹⁾, Z⁽²⁾ 用相同、保留正误的 support；**复用 D1 已冻结的概念关系池**（正对=同学生同概念跨结构且锚证据充足，或独立证据支持的跨学生正对；负对=同概念、表现匹配、独立证据显示明确差异），相似度用概念坐标固定尺度距离核；关系资格不由当前后验熵决定（防"把困难样本判成不确定"逃避损失）。监测边熵与两视图差异率——CL 可能通过让 π 过早趋 0/1 消除视图差异，低熵不是恢复真结构的证明。
5. 推理：正式预测用 M=16 张采样结构的平均（固定评估采样种子并检查采样误差）；均值 π 前向是速度近似，**单独报告，不混入同协议**。

**验证设计**：必须先在已知真 Q 的合成数据上分别施加漏标/多标/混合噪声，匹配总污染量用 `r = (1−s)f + s·n`（s 为真边密度），不能比较 f+n；报告边 precision/recall、Q-AUPRC、行级完全恢复率、概率校准、不同边类型的不确定性，以及预测四指标。真实参考 Q 再加人工噪声时，恢复目标只是"额外施加的扰动"，须与全合成实验分开。

| 专属对照 | 排除的混杂 |
| --- | --- |
| 固定连续软 Q | 现有强对照 |
| 冻结 π + 同样采样及预测平均 | 随机结构与模型平均本身的收益 |
| 学习后验（对称通道，无 CL） | 结构学习基本收益 |
| 学习后验（非对称通道，无 CL） | 非对称噪声假设的收益 |
| 非对称通道 + 结构 CL | CL 的增量 |
| 上项但阻断 CL→Q | 对比是否真的改善结构分布 |
| 相同边改动率的均匀随机结构视图（只替换 CL 辅助分支，变分项不变；扰动强度用训练期停止梯度两视图 Hamming 率匹配） | 后验产生视图是否优于普通扰动 |

**支持创新**：匹配污染量的多种噪声类型下，非对称通道与结构 CL 各有可重复贡献；结构不确定性与真实错误相关；真实预测未因强一致性受损。**失败条件**：收益全部来自 Monte Carlo 集成；CL 只让后验提前硬化；对噪声率极端敏感；Q 与噪声参数互相迁就——回退确定性方案，不用贝叶斯术语包装无效模块。

## 六、新增方向 6：可学习 Q 下的可辨识性保持（IPW-Q）

> 实验 ID：`wqcl_d6_identifiability_v1`。性质：阶段1 为**纯评估**（零训练），阶段2 才加训练约束。

### 6.1 一句话

**系统测量"把固定 Q 换成可学习 Q 之后，生成式诊断的可辨识性是否退化、何时退化"，若退化则给出一个保持表示分离性的训练约束。**

### 6.2 想法来源

1. **基础论文的核心卖点**：生成式范式的诊断结果"可辨识"——相同作答分布映射到相同诊断结果，且不同分布映射到不同结果（论文 Eq.4/5）；论文 Table IV 中 G-IRT/G-NCDM 的 IDS=1.000，而 transductive 基线最低只有 0.041（MIRT）。这是"生成式 vs 翻转式"叙事的支柱之一。
2. **我们的扩展恰好动摇了它的前提**：Weak-Q 让 Q 可学习。GDF 仍无逐学生自由参数（结构上可辨识的来源未破坏），但存在三个可测量的退化风险：
   - Q 稠密化（hard density 0.33–0.64）使 `θ_exp = σ(RQ/√K)` 进入饱和区，不同作答向量的 θ 被压缩；
   - test_sim_con 记录的掌握表示有效秩普遍下降（如 fixed soft Q：ASSIST 3.52→1.52）；
   - 弱先验把 Q 拉向 P0，不同学生的差异被"共同的 Q"部分抹平。
3. **没有任何人检验过这件事**——包括原论文自己（其 IDS 只在固定 Q 下评估）。基础论文代码仓库也没有 IDS 的实现。这是"站在基础论文肩膀上的批判性延伸"：如果可辨识性确实退化，等于发现了一个 prior work 未报告的 trade-off；如果不退化，等于为 Weak-Q 补上了一个重要性质的确认实验。**两个结果都能写**。

### 6.3 为什么可以作为一个创新

| 最近邻 | 覆盖什么 | 与本方向的差异 |
| --- | --- | --- |
| [Gu & Xu 的可辨识性理论系列](https://scholar.google.com/scholar?q=Gu+Xu+Q-matrix+identifiability) | DINA 类模型的可辨识性充要条件（理论） | 理论条件，不涉及深度模型训练动态 |
| Kim (2025, BJMSP) 可辨识性条件与 Q 矩阵估计 | 估计算法的可辨识性含义（统计） | 传统 CDM 框架，无神经网络、无可学习软 Q |
| 原论文（arXiv:2507.09831） | 把 IDS 作为生成范式的评估指标（固定 Q） | 不研究 Q 可学习时的 IDS 变化，无训练约束 |
| [M-QCDNet (arXiv:2607.01278, 2026)](https://arxiv.org/abs/2607.01278) | Q 矩阵嵌入的多层网络结构 | 结构设计，不关心可辨识性度量 |

**候选贡献声明（待验证）**：① 问题层——首次系统刻画"结构可学习性 ⇄ 诊断可辨识性"在深度生成 CD 中的权衡；② 方法层——提出保分离性的排序约束（见 6.5），并检验它与预测收益的兼容性。**这个方向与基础论文的对话性是十个点里最强的，非常适合作为论文的"可靠性/分析"章节核心。**

### 6.4 如何实现：阶段 1——探针式可辨识性评估（零训练）

原论文 IDS 用"作答分布相同的 shadow learners"（增广数据），真实数据上直接复制有困难。给出三个可直接落地的度量，全部**只读已有 checkpoint**：

1. **探针注入度检验（probe injectivity，主度量）**：从训练作答矩阵的行分布采样 M=2000 个作答向量 `R^(t)`（有真实学生的直接用真实行），构造近邻对：把 `R^(t)` 随机改 h 条已观测位（h=1,2,3）得到 `R^(t,h)`；输入训练好的 GDF 得 `θ^(t), θ^(t,h)`。度量：
   `Sep(h) = mean[ ||θ(R)−θ(R')||₂ / sqrt(h) ]` 与 `Mono(h) = P[ ||θ(R)−θ(R')||₂ > ε_sep | h≥1 ]`。
   语义：作答差 1 条，θ 至少应动多少；h 越大分离度应越大。**若模型可辨识，Sep(h) 应明显大于 0 且随 h 单调**；transductive 模型（逐学生 embedding）在同协议下应接近 0——这正好复现论文 Table IV 的排序，作为实现正确性的 sanity check。
2. **近重复学生 IDS（论文 Eq.40 的真实数据适配）**：找出作答向量汉明距离 ≤ 2 的真实学生对（20 题的 Math1、16 题的 Math2 存在；多题数据集限制 h=1），按 Eq.40 计算 `[1+dist(θ_i,θ_j)]^{-2}` 的加权统计；报告各模型的分层 IDS。
3. **分布保持检验**：θ 的跨学生分位数曲线（各模型对比），检测"表示收缩"（与有效秩记录互相印证）。

落点：`Q_GNCDM/experiments/evaluate_identifiability.py`（新增，只读 checkpoint，复用 `run_prepared_dataset.load_data` 与 `run_simple_contrastive.build_model` 的重建逻辑，仿照 `evaluate_test_sim_con_robustness.py` 的"读 manifest → 重建 → 重放"骨架）。对已有结果目录直接跑：fixed_binary / fixed_soft / learned_no_prior / weakq_no_cl 各条件的 checkpoint（Math1 系列在本地就有，其余在 Gen-CD）。

**阶段 1 判据**：weakq 系相对 fixed_binary 的 Sep(h) 或 IDS 下降超过 20%（相对值）→ 确认退化，进入阶段 2；否则 → 负结果，写入论文可靠性章节（"弱监督可学习 Q 不损害可辨识性"是重要的确认性结论），方向 6 关闭。

### 6.5 如何实现：阶段 2——保分离性的排序约束

若确认退化，加入训练约束（对 batch 内可计算的学生对）：

```text
d_resp(i,u)  = 汉明距离(support_i, support_u) / sqrt(观测数)     # 作答差异
d_theta(i,u) = ||θ_i − θ_u||₂ / sqrt(K)                          # 诊断差异
L_sep = mean over 对(i,u) with d_resp(i,u) ≥ δ_min:
        softplus( (d_resp(i,u) − d_resp(i',u')) / T
                  − (d_theta(i,u) − d_theta(i',u')) / T )        # 保序：作答差异大的对，
                                                                  # 诊断差异不允许更小
```

- 作用路径：`L_sep → θ → θ_exp → Q`（也经过 f_φ，属全网络约束；用 `idea_detach_q` 式对照区分）。
- 防作弊：θ 有界于 [0,1]^K（sigmoid 输出），放大尺度的空间有限；仍需记录 d_theta 的实际分布与饱和比例。
- 条件：`sepq_no_cl`（0.95/0.05 初始化 + L_sep，无 CL），λ_sep ∈ {0, 1e-3, 1e-2, 1e-1}；关键对照是 weakq_no_cl（同起点无约束）。
- 判据：验证 AUC 不劣（≥ −0.001）且 Sep(h)/IDS 恢复到 fixed_binary 的 90% 以上 → 完整故事成立。
- 停止条件：L_sep 与预测损失长期冲突（梯度夹角持续 >120°）且验证 AUC 下降 >0.002 → 缩小结论为"权衡存在，无法免费恢复"。

### 6.6 成本与风险

- 阶段 1：1–2 天（实现 + 对已有 checkpoint 批量评估）。风险低。
- 阶段 2：一周内。主要风险是排序对的采样效率（Math1 每人仅 10 条 support，h=1 的对可能大量重复——记录配对覆盖率）。
- 论文价值：无论结果正负都可写；与方向 10 的"分证据量评估"共用大量基础设施。

## 七、新增方向 7：边级置信度加权的弱监督（ECW-Q）

> 实验 ID：`wqcl_d7_edge_confidence_v1`。性质：统计量实现为主，模型改动极小。

### 7.1 一句话

**用经典心理测量学的 Q 校验统计量，为参考 Q 的每条边计算数据驱动的置信度 c_jk，把均匀的弱先验 `mean(Q−P0)²` 升级为边级加权 `mean(c ⊙ (Q−P0)²)`——让"我很确定的边"锚得住，"可疑的边"放得开。**

### 7.2 想法来源

1. **关键观察（来自 test_sim_con）**：移除 soft-prior MSE 后，五套数据的 AUC 差值只有万分之一量级——**当前的均匀弱先验几乎没起作用**。要么把它做对（边级置信度），要么承认它没用。这是把"先验失效"从 bug 变成研究机会的切入点。
2. **先验的均匀性明显不合理**：参考 Q 的边可靠性差异巨大——math2 是真专家标注，eedi/assist/junyi 是 metadata/标签派生；同一矩阵内，单概念题的标注几乎不会错，多概念题、跨学 科题的标注常常含糊。均匀 MSE 对两者一视同仁。
3. **经典心理测量学有现成的统计量**，只差"搬进深度模型"这一步：
   - [Chiu (2013) 的残差 Q 矩阵修正](https://link.springer.com/article/10.1007/s11336-013-9344-5)：非参数残差检验逐条修正 Q；
   - de la Torre (2008) 的经验 Q 矩阵修正：基于条件残差相关；
   - [Liu, Xu & Ying (2012), Data-driven Learning of Q-Matrix, Applied Psychological Measurement 36(7)](https://doi.org/10.1177/0146621612456591)（被引 ~277）；
   - Qin et al. (2015) 的增量式 Q 推断。
4. **合成数据提供了干净的验证场**：`generate_synthetic_weak_q.py` 精确记录了每条噪声边的位置（`noise_info_*.json` 的 deleted/added/flip 列表）。**"置信度统计量能否找到被注入的噪声边"是一个有唯一正确答案的实验**——这是十个点里验证最干净的。

### 7.3 为什么可以作为一个创新

| 最近邻 | 覆盖什么 | 与本方向的差异 |
| --- | --- | --- |
| Chiu 2013 / de la Torre 2008 / Qin 2015 | 经典统计量做 Q 修正（统计层） | 产出是修正后的 0/1 矩阵；这里产出是**可微分的边级先验权重**，接入深度生成 CD 的弱监督通道，且保留原标注（只改信任度） |
| Regularized Bayesian Q (BJMSP 2025, [JEBS 2025](https://journals.sagepub.com/doi/10.3102/10769986241240084)) | 部分 expert 指定+部分数据推断的贝叶斯/正则框架 | 全模型贝叶斯推断；这里是"冻结统计量 → 加权先验"的轻量桥接，消融结构更简单 |
| Human-AI Q 精炼（[arXiv:2604.16398](https://arxiv.org/html/2604.16398v1), 2026） | LLM/人工协作修正 Q | 依赖外部语义信息；本方向只用作答+参考 Q |
| 已失败的"证据计数加权一致性"（test_sim_con） | 用证据数加权 CL 损失 | 权重来源（计数 vs 校准统计量）与加权对象（CL 损失 vs 弱监督目标）都不同；**必须把它列为对照** |

检索确认："confidence-weighted weak supervision for Q-matrix"这一组合在检索中没有直接命中（检索器明确提示该组合可能是空白）。**候选贡献**：把经典 Q 校验统计量转化为深度生成 CDM 中可学习 Q 的边级先验权重，并用合成注入实验建立统计量→噪声边的可追踪性。⚠️ 风险提示：如果三个统计量在合成数据上都找不到噪声边（AUC≈0.5），方向应立即止损——这说明"参考 Q 的噪声在作答证据中不可识别"，本身也是一个值得报告的负结果。

### 7.4 如何实现

**第一步：边级置信度统计量**（`experiments/build_edge_confidence.py`，新增）。三个候选实现，由简到繁：

1. **c1 锚残差判别量**（推荐首选）：交叉拟合 Rasch（固定三折，与 D1/D3 共享基础设施）得残差 `ρ_ij = m_ij(y_ij − p̂^g_ij)`；对概念 k，用单概念题（|Q_j|=1）当锚，定义学生概念代理 `g_ik = mean_{j∈锚_k} ρ_ij`；边 (j,k) 的置信度 = "g_ik 高组与低组在题 j 上的残差差"的标准化统计量（t 型或 AUC 型，按组内样本量收缩，样本不足时回退 0.5）。
2. **c2 题对相关一致量**（de la Torre 式）：题 j 与概念 k 其他锚题的残差相关，减去题 j 与非 k 题的平均相关，再标准化。
3. **c0 降级版**（若无时间做 1/2）：`c_jk = specificity(Q_j) = 1/|Q_j|`（单概念题=1，多概念按概念数衰减）——实现半小时，先拿它跑通管线。

输出：`edge_confidence.npy`（与 Q 同形）+ 报告（各统计量的分布、与参考 Q 密度的相关）。

**第二步：合成数据可追踪性验证**（阶段 0，有唯一正确答案）：对 seed_2026 的每个噪声档，计算"c 对噪声边的判别 AUC"（以 noise_info 的边位置为标签）。**门槛：c1 或 c2 的 AUC ≥ 0.70 才有资格进入真实数据实验**；c0 预期较低（它只知道"多概念可疑"，不知道"哪条边错"）。

**第三步：加权弱监督**（模型小改动）：`models/weak_q_gncdm.py` 增加 `register_buffer("q_conf")` 与 `weak_q_loss_type="mse_conf"` 分支：`loss_weak_q = mean(c ⊙ (q_soft − Q_prior)²)`。c 冻结（来自交叉拟合统计量，不参与梯度——保持"置信度是外部证据"的可解释性）；学习版 c 作为后续扩展，不进首版。

**第四步：三方对照**（阶段 2，三种子配对）：

| 条件 | 弱监督 | 回答什么 |
| --- | --- | --- |
| weakq_no_prior | 无 | 下界 |
| weakq_no_cl（=现状 uniform） | 均匀 MSE | 现状基线 |
| ecwq_no_cl | c 加权 MSE | 本方向 |

再 × {0.95/0.05 初始化}，λ_q ∈ {0.001, 0.01, 0.1}（按有效监督单位归一后可比）。合成数据上额外报边级 precision/recall/AUPRC（对真 Q），真实数据报参考一致性 + 预测。

**判据**：合成上 ecwq 的边级 AUPRC > uniform 且噪声边修复率提升；真实上验证 AUC 不劣且（若合成迁移性成立）结构指标改善。**停止条件**：合成 AUC < 0.6（统计量不可追踪）；或加权后预测显著变差且无结构补偿。

### 7.5 成本与风险

- 统计量管线（交叉拟合 Rasch + 三种 c）：3–4 天；模型改动半天；对照实验 2–3 天。合计约一周半。
- 与方向 9 共享交叉拟合 Rasch 基础设施——**建议 7 和 9 排在一起做**。
- 主要风险：真实数据的锚题不足（assist2012 的 Q 密度只有 0.010，单概念锚题可能很少）——c0 降级版保底；统计量在稀疏学生上方差大——按证据量收缩并报告。

## 八、新增方向 8：Q 信任域扰动一致性（TRQ）

> 实验 ID：`wqcl_d8_trust_region_q_v1`。性质：实现最快（一天内可出首个 smoke），是"固定软 Q 为什么有效"的直接推广。

### 8.1 一句话

**训练时对当前 Q 做信任域内的小扰动（随机或对抗方向），要求扰动前后的 query 预测一致——把"固定软 Q 的平滑收益"从静态初始化升级为显式的动态正则，并顺带完成悬置已久的"软 Q 收益来自哪条路径"归因。**

### 8.2 想法来源

1. **项目内最强的经验事实**：固定 0.95/0.05 软 Q 是 test_sim_con 里收益最清楚的对照（五套数据 Δ测试 AUC +0.0006 ~ +0.0088，3/3 种子同向）。它本质上是一种**固定的、全局均匀的 Q 平滑**。
2. 顺着这个解释，自然产生两个问题：① 平滑是否可以做成训练时的正则（而不是初始化）？② 平滑应该是均匀的，还是应该定向（最坏情况）？——这正是随机扰动 vs 对抗扰动的一对消融。
3. **与已失败机制的辨析**（test_sim_con 已证伪的六种都在"作答扰动 + 表示对比"里）：TRQ 扰动的是**结构张量 Q**，一致性目标是**query 预测**（不是表示），约束是**信任域**（不离开弱先验允许的邻域）。作用路径：Q 同时进入 `θ_exp = σ(RQ/√K)` 与 IRF 掩码两条路径，扰动一致性会同时平滑两者——这也是它区别于作答增强的根本点。

### 8.3 为什么可以作为一个创新

| 最近邻 | 覆盖什么 | 与本方向的差异 |
| --- | --- | --- |
| [ATKT (Guo et al., ACM MM 2021)](https://doi.org/10.1145/3474085.3475554) 及其后续（MDKT、对抗对比 DKM, Ju et al. 2026） | 对 KT 的**交互嵌入/题目表示**做对抗扰动 | 扰动对象是序列嵌入；这里是**Q 结构张量**，且在生成式 CD 框架内、有弱先验信任域约束 |
| SVGCD (WWW Companion 2025，原文档已引) | 变分图视图 + 语义对比 | 图视图服务于表示对比；TRQ 的扰动直接服务预测一致性，确定性、无变分机器 |
| R-Drop 类一致性正则 | 网络随机性（dropout）一致性 | 扰动源是模型随机性；TRQ 的扰动源是结构参数空间，有明确语义（"允许 Q 摆动多少"） |
| 固定软 Q（本项目对照） | 静态均匀平滑 | TRQ 是其动态化/定向化推广，且退化条件明确（λ_trq→0 且 δ→0 恢复现状） |

检索确认：对 **CDM 的 Q 矩阵本身**做对抗/扰动一致性训练，在检索中没有直接命中（检索器提示"CD 对 Q 扰动的对抗鲁棒性相当小众"）。**候选贡献**：① 给出"固定软 Q 有效"的机制解释（隐式结构平滑）及其可泛化的显式形式；② worst-case vs random 扰动的对照回答"平滑应该均匀还是定向"。

### 8.4 如何实现

```python
# 每个 training step（在现有 episode 协议内）：
Q_hat = model.get_q_soft()                                  # 当前可学习 Q
if mode == "random":
    U = torch.empty_like(Q_hat).uniform_(-delta, delta)     # 随机信任域扰动
elif mode == "adv":
    g = torch.autograd.grad(loss_pred, model.q_logits, retain_graph=True)[0]
    U = delta * torch.sign(g)                               # 一步最坏方向（对 q_logits）
Q_tilde = torch.clamp(Q_hat + U, lo, hi)                    # 信任域，如 [0.05, 0.95]
pred_tilde = predict_with_Q(theta_clean, psi, Q_tilde[query_items])
loss_trq = kl_div(pred_tilde, pred_clean)                   # 一致性：扰动视图的预测
                                                            # 不得偏离主视图；主 BCE 的
                                                            # 梯度路径不经 Q_tilde
# loss = loss_pred + λq·L_weakQ + λ_trq·loss_trq
```

四个必须落到代码的细节：

1. **扰动只进辅助前向**：主 BCE 的预测用 `Q_hat`；`Q_tilde` 只出现在一致性项，避免把扰动泄漏进主梯度。
2. **对抗版的梯度来源**：对 `q_logits` 求一步符号梯度即可（FGSM 式）；不要做多次迭代（成本失控）。
3. **信任域语义要报告**：δ 的含义是"允许每条边在一个 step 内摆动 ±δ"；lo/hi 由弱先验语义决定（0.95/0.05 初始化时取 [0.05, 0.95]）。δ ∈ {0.05, 0.1, 0.2}。
4. **双路径归因消融**（本方向的独特副产品）：扰动可以只作用 IRF 掩码路径（`predict_response` 内的 `Q_batch`）或只作用显式生成路径（`diagnose_theta` 内的 `Q_soft`）或两者——三组对照直接回答 test_sim_con 悬置的"软 Q 收益来自哪条路径"。

**消融表**：

| 条件 | 扰动 | 检验什么 |
| --- | --- | --- |
| fixed_soft | 无（静态平滑） | 现有最强对照 |
| trq_random | 随机 ±δ | 动态平滑的收益 |
| trq_adv | 对抗 ±δ | 定向平滑是否更好 |
| trq_edge_dropout | 伯努利置零边 | 置零式 vs 加噪式 |
| trq_mask_only / trq_exp_only | 单路径扰动 | 收益来自哪条 Q 路径 |
| λ_trq ∈ {0, 0.01, 0.1, 1} | — | 系数敏感性（0 是必需对照） |

**判据**：trq_random 的验证 AUC ≥ fixed_soft 且 ACC 不劣 → "动态平滑至少不差于静态"；trq_adv > trq_random → "定向平滑有额外价值"；若 TRQ ≈ fixed_soft → 结论"静态软化已足够"，作为消融结论写入论文（仍有价值，因为它完成了路径归因）。**停止条件**：δ 大到破坏弱先验语义（Q 结构漂移出信任域）或训练不稳定。

### 8.5 成本与风险

- 实现 1 天（一个辅助前向 + 一行符号梯度），smoke 当天可跑；三种子消融 2–3 天。**是十个点里投入产出比最高的**。
- 风险：对抗符号梯度的 `retain_graph` 增加约 30% 训练时间（可接受）；一致性项与 BCE 的量纲差异——按有效监督单位归一并记录 `r_Q` 梯度比（原文档 8.5）。

## 九、新增方向 9：单概念锚校准的概念归因分解（SACA）

> 实验 ID：`wqcl_d9_anchor_attribution_v1`。性质：参数化设计保证"退化即原模型"，归因贡献可被干净消融。

### 9.1 一句话

**多概念题的作答证据目前被均摊给它标注的每个概念；SACA 学习行内归因权重 Ã（仅在 Q=1 的支持集上分配、行内总质量守恒），并用单概念题校准的"概念残差水平"作为监督信号，使归因向真实的概念构成收敛。**

### 9.2 想法来源

1. **真实痛点**：Q 的行常常多概念（Math1 每题平均 3.35 个概念；synthetic 1–3 个）。当前 `θ_exp = σ(R·Q/√K)` 把一道 3 概念题的错答**均等地**记到 3 个概念上——但实际可能只是"函数"没掌握而"几何"没问题。均摊归因系统性稀释概念诊断。
2. **数据里有免费的校准锚**：|Q_j|=1 的单概念题，其残差无歧义地指向一个概念。用它们校准"学生在概念 k 上的残差水平 t_ik"，多概念题的归因就应使"归因后的概念残差"能解释该题的实际残差。
3. **合成数据有归因真值**：generator 的 `item_discrimination[j,k]`（只在 Q=1 处生效）就是"该题真正依赖各概念的程度"——归一化后即归因真值。**学到的 Ã 是否更接近它**，又是一个有唯一正确答案的验证实验（与方向 7 同风格）。

### 9.3 为什么可以作为一个创新

| 最近邻 | 覆盖什么 | 与本方向的差异 |
| --- | --- | --- |
| DCD (NeurIPS 2023，原文档已引) | 有限标签下学习题目标签分布 | 需要有限的人工标签监督；SACA 只用作答 + 参考 Q 的单概念锚，零额外标注 |
| [Disentangling Heterogeneous Knowledge Concept (arXiv 2024)](https://arxiv.org/html/2405.16003v2) | 概念解耦诊断 | 解耦的是概念空间表示；SACA 解的是"单题证据在概念间的分配"，作用于显式分支聚合，且有退化等价设计 |
| Zhang et al. (2025，多概念题可学习概念权重) | 可学习概念权重（英语学习推荐场景） | **最硬的近邻**：贡献必须落在"锚校准机制 + 行质量守恒的退化等价设计 + 合成归因恢复评估"，不能声称"可学习概念权重"本身 |
| Sun et al. (2026，拓扑概念难度缩放) | 多概念题的认知负载建模 | 用图拓扑定缩放；SACA 用作答残差校准 |

**候选贡献声明（待验证）**：把多概念题的证据归因从"固定均摊"升级为"单概念锚校准的可学习归因"，保持每题总证据量不变（因此与原模型的差异**只**来自归因重排，可精确归因），并在合成数据上验证归因恢复。

### 9.4 如何实现

**参数化（关键设计：退化等价 + 质量守恒）**：

```text
支持集 S_j = {k : Q_jk = 1}
A_j = masked_softmax(w_j) over S_j        # w_jk 可学习，初始化为 0 → A 均匀
Ã_jk = A_jk · |Q_j|  (k ∈ S_j)；Ã_jk = 0 (k ∉ S_j)
θ_exp = σ( R · Ã / √K )
```

- 均匀初始化时 `Ã = Q`（因为 `A_jk·|Q_j| = |Q_j|/|S_j|·|Q_j|`？——**注意**：均匀时 `A_jk = 1/|S_j|`，故 `Ã_jk = |Q_j|/|S_j| = 1`，恰好等于 `Q_jk`；行内求和 `Σ_k Ã_jk = |Q_j|` 与原 Q 行和一致）。**即：w=0 时模型与当前 weak-Q 逐数值一致**——归因学习的净贡献可以被干净地消融（这是与 Zhang et al. 2025 区分的关键设计）。
- IRF 掩码仍用原 Q（不动）；归因只改显式分支的聚合。若后续要让归因也进 IRF，作为独立实验单列（那会变成另一种 Q 编辑，与 D2 的边界要写清）。

**归因监督（核心损失）**：设交叉拟合 Rasch 残差 `ρ_ij = m_ij(y_ij − p̂^g_ij)`，单概念锚题集 `E_k = {j : |Q_j|=1, Q_jk=1}`，学生在概念 k 的锚校准水平 `t_ik = mean_{j∈E_k∩sup_i} ρ_ij`（**计算 t 时排除题 j 自身**，防自匹配）。对多概念题 j（|Q_j|≥2）：

```text
L_attr = Σ_j Σ_{k∈S_j} Ã_jk · huber( ρ̂_ij − t_ik^(−j) ) / |S_j|
```

语义：题目 j 的残差应由"归因加权的概念水平"解释；若某概念在 j 上被过度归因，其 t_ik 与 ρ_ij 的错配会推低该边的 A。t 的稳定性按锚题数收缩（锚题 <2 时该边退出损失）。

**可选 CL 耦合**（最后再做，不进首版）：归因后的概念残差 `z_ik` 可以作为 D1/D3 的对比输入——这是与既有方向的天然组合点。

**消融表**：

| 条件 | 归因 | 检验什么 |
| --- | --- | --- |
| saca_uniform（w 冻结为 0） | 均匀=现状 | 等价性核验（应与 weakq_no_cl 逐数值一致） |
| saca_learned | 学习 Ã | 归因的净贡献 |
| saca_frozen_t | t 用冻结教师 | 监督来源稳定性 |
| saca_no_anchor_t | t 换成原始正确率 | 难度校正的必要性 |
| （合成）Ã vs 归因真值 | — | 归因恢复：Ã 与 `item_discrimination` 归一化真值的相关/AUC，对照均匀 |

**判据**：合成上 Ã-真值相关显著高于均匀归因（对照）且预测不劣；真实上验证 AUC 不劣 + 跨种子归因稳定（同一对 (j,k) 的 A 排序一致率 >70%）。

### 9.5 成本与风险

- 与方向 7 共享 Rasch 交叉拟合基础设施；总实现约一周。
- 风险：① 真实数据单概念锚题不足（assist2012 尤甚）——按数据集报告锚覆盖率，不足时如实说"该数据不适合此方向"；② 归因与预测目标的冲突（模型可能用归因搬运总表现）——保留弱先验并监测 Ã 的熵分布；③ 与 Zhang et al. 2025 的差异化必须在论文里主动引用并划界。

## 十、新增方向 10：证据自适应的解析锚定即时诊断（E3A）

> 实验 ID：`wqcl_d10_evidence_anchor_v1`。性质：阶段1 为评估协议改造 + 零训练分析；阶段2 改显式分支。

### 10.1 一句话

**当学生作答证据很少（新学生、低活跃用户）时，把诊断收缩为"总体能力锚 + 幅度受证据量控制的概念偏移"：总体能力锚来自解析式 G-IRT 型闭式估计（本仓库现成资产），概念偏移的幅度随有效证据量增长——补上原论文"即时诊断"卖点中从未被检验的"证据效率"一环。**

### 10.2 想法来源

1. **基础论文的卖点一**是即时诊断（新学生零重训练，×100 提速）；但"新学生只有 2–5 条作答时诊断质量如何"从未被评估——原文档 8.3 明确把"真正新学生冷启动"列为边界。
2. **机制层面的真实问题**：低证据时 `θ_exp = σ(R·Q/√K)` 严重欠采样（Math1 每人 support 仅 10 题、11 个概念，摊到每概念 <1 条）；隐式分支 f_φ 对训练分布外的稀疏输入行为不可控。诊断质量随证据量的衰减曲线没有人刻画过。
3. **本仓库独有资产**：`GIRT/model/girt_arch.py` 的解析式 G-IRT（θ = proxy 参数的闭式加权平均，论文 Eq.22）。它的稀疏证据行为**可解析分析**（论文 Eq.23–30 正是干这个的），且对新学生零成本可用。当前 weak-Q 主线完全没用上它。
4. **统计直觉**：低证据时最优估计应向先验收缩（经验贝叶斯）；先验在这里的自然选择是"总体能力"（所有概念共享），概念分化信息随证据积累才逐渐可信。

### 10.3 为什么可以作为一个创新

| 最近邻 | 覆盖什么 | 与本方向的差异 |
| --- | --- | --- |
| [LMCD (arXiv 2025)](https://arxiv.org/html/2505.21239v2) | LLM 辅助的冷启动 CD | 引入语义/文本信息；E3A **不需要任何外部信息源**，纯证据效率 |
| [知识概念冷启动 (Neurocomputing 2026)](https://www.sciencedirect.com/science/article/abs/pii/S0925231226001670) / Gao et al. 2024 域级零样本 | 新**领域**零样本诊断 | 解决"新领域无数据"；E3A 解决"同领域内证据稀疏的学生"，是正交问题 |
| UCD (WWW 2024，原文档已引) | 诊断不确定性估计 | 输出不确定性；E3A 直接改进点估计的证据效率，且给出收缩的显式机制 |
| 原论文 instant diagnosis | 不重训练即可诊断 | 解决"速度"，不解决"证据太少时质量塌陷" |

**候选贡献**：① 把"证据效率"引入生成式 CD 的显式分支（自适应收缩），退化条件明确（证据充足时精确恢复原模型）；② 建立**分证据量的评估协议**（按 support 大小分桶报告），这是全项目缺失的基础设施，任何方向都受益；③ 与原论文"空学生识别"发现（Finding 2）形成理论呼应：n_eff→0 时所有学生收敛到同一点——空学生被收缩机制自动识别。

### 10.4 如何实现

**组件 1：解析总体能力锚 a_i**（对每个学生的 support 计算，零训练）：

```text
a_i = σ( ( Σ_{j∈sup_i} ω_j · R_ij + λ · Σ_{j∈sup_i} 1 ) / ( Σ ω_j ·观测数 ) 的 G-IRT 型闭式 )
```

直接复用 `GIRT/model/girt_arch.py::get_respondent_parameters` 的逻辑：proxy 参数（ω_a, ω_b）换成在**训练集全体学生**上一次性拟合好的固定值（跑一遍 G-IRT 训练或用解析初始化），新学生的 a_i 只是闭式代入。输出压到 [0,1]。

**组件 2：证据自适应收缩**（改显式分支）：

```text
n_eff_i = Σ_j∈sup_i Σ_k Ã_jk 的有效证据量（或逐概念取 min 后聚合）
α_i = α_max · n_eff_i / (n_eff_i + n_0)          # 显式分支权重随证据增长
θ_exp_raw = σ( R_i · Ã / √K )
θ_exp_i   = a_i·1 + β_i · (θ_exp_raw − a_i·1)    # 向总体能力锚收缩
β_i       = n_eff_i / (n_eff_i + n_0)            # 概念分化幅度随证据增长
```

- 退化核验：`n_eff → ∞` 时 `α_i → α_max, β_i → 1`，精确恢复原 weak-Q；`n_eff → 0` 时 θ → 锚的先验位置（所有低证据学生趋同——空学生识别的形式化）。
- n_0 是唯一新超参（验证集选；量级 = "多少条作答后概念分化开始可信"，起步 5）。

**组件 3：分证据量评估协议**（零训练，先做）：

- 把 valid/test 学生按 support 大小分桶（如 [0,5), [5,10), [10,20), ≥20；Math1 题少桶少，eedi/junyi 分布宽），逐桶报告 AUC/ACC/掌握排序（合成数据报掌握误差）。
- **对已有 checkpoint 直接出第一张表**：fixed_binary / fixed_soft / weakq_no_cl 各条件在低证据桶的衰减曲线——这本身就是论文素材（"现有方法在低证据学生上衰减多少"）。

**阶段 2 对照表**：

| 条件 | 收缩 | 锚 | 检验什么 |
| --- | --- | --- | --- |
| weakq_no_cl | 无 | 无 | 现状基线 |
| e3a_adaptive | 自适应 β | 有 | 完整方案 |
| e3a_fixed_alpha | 固定 α，无 β | 有 | 锚的净贡献（不含自适应） |
| e3a_shrink_only | 自适应 β | 无 | 纯收缩的净贡献 |
| e3a_no_anchor_fit | 锚换成学生正确率 | 简单基线 | 解析锚是否优于朴素统计量 |

**新学生协议**（补冷启动空白）：从 test 学生随机抽 k ∈ {1, 2, 5, 10} 条作答做诊断，比较各方法的"少证据诊断曲线"（对合成数据可对真掌握排序；对真实数据报对剩余作答的预测 AUC）。

**判据**：低证据桶（如 support<10）的 AUC/掌握排序相对基线提升 ≥0.005，且高证据桶不劣（退化核验通过）；合成数据的掌握误差在低证据桶明显下降。**停止条件**：收缩导致高证据桶受损、或锚与 f_φ 分支长期冲突。

### 10.5 成本与风险

- 阶段 1（评估协议 + 已有 checkpoint 分析）：1–2 天，零训练风险。
- 阶段 2（G-IRT proxy 拟合 + 显式分支改造 + 对照）：约一周。
- 风险：① Math1/Math2 每人 support 固定（20 题），分桶退化为单桶——分证据量评估的主力是 eedi/assist/junyi；② 收缩机制与 query 隐藏协议的交互（episode 内 support 变小会触发收缩——这其实是**特性**：训练时自动看到各种证据量，但要检查训练/评估的 n_eff 分布一致性）。

## 十二、统一指标与判据（原文档 8.6 的补充）

完全沿用原文档 8.6 的四层指标体系（预测层 AUC/ACC/NLL/Brier、结构层 Q 统计、诊断层、优化层），本方案补充各新方向的特有指标：

| 方向 | 特有指标 | 有效收益的最低标准 |
| --- | --- | --- |
| 6-IPW-Q | Sep(h)、近重复 IDS、探针单调性、饱和比例 | 阶段1：相对下降 >20% 即"确认退化"；阶段2：恢复至 fixed_binary 的 90% 且 AUC 不劣 |
| 7-ECW-Q | c 对噪声边的 AUC、边级 AUPRC、按 c 分层的边修复率 | 合成 AUC ≥ 0.70 才进真实实验 |
| 8-TRQ | 信任域边界漂移量、扰动前后预测 KL、双路径归因分解 | trq_random ≥ fixed_soft 且 ACC 不劣 |
| 9-SACA | Ã-归因真值相关（合成）、跨种子归因一致率、锚题覆盖率 | 合成相关显著高于均匀且预测不劣 |
| 10-E3A | 分证据桶 AUC/掌握误差曲线、退化核验（高证据桶无差异）、新学生 k-shot 曲线 | 低证据桶 ≥ +0.005 且高证据桶不劣 |

通用的结论纪律（照搬原文档并强调）：增益只有 1e-4 量级时不得宣称有效；AUC 升 ACC 降必须写明权衡；每个方向完整记录探索范围；最终确认必须在未参与选择的评估上做。

## 结语

十个点的共同纪律：**每条路线先回答"它要解决的问题是真实存在的吗"（用本项目已有证据回答），再回答"机制是否能被干净地证伪"（等价性/退化性/合成真值），最后才是"指标涨没涨"。** 建议从第一梯队（8、6、10 的评估部分）起步——两周内即可知道 Q 侧这条主线还有多少可挖的空间，再决定资源投向。
